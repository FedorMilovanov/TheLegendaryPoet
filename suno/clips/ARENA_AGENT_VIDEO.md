# ARENA AGENT — Видео

Работа с видео THE LEGENDARY POET в ChatGPT и LM Arena: motion-промты,
image-to-video, отбор и техническая подготовка исходных роликов к монтажу.
Общие правила принадлежат [AGENT](AGENT.md), [ANIMATION](ANIMATION.md),
[STORAGE](STORAGE.md) и профильному проекту/кейсу. Для статики —
[ARENA AGENT — Картинки](ARENA_AGENT_IMAGES.md).

## 1. Две рабочие среды

- **ChatGPT:** готовь самостоятельные копируемые motion-промты по присланным
  или выбранным кадрам; фактическое видео создавай только при соответствующем
  запросе и наличии инструмента. Локальная техническая обработка допустима
  через разрешённый инструмент с соблюдением ресурсных правил.
- **LM Arena:** один и тот же кадр с одним промтом можно направить двум моделям
  в поддерживаемом режиме сравнения; возможны и отдельные генерации.
  При ручном запуске владелец загружает кадр, запускает и выбирает результат.
- Не предполагается общий доступ к файлам, истории, кредитам или результатам.
  Передавай точный исходник и промт, а для продолжения — фактически доступные
  видео. Не выдавай текст задания за созданный или просмотренный ролик.

## 2. Один промт для двух ИИ

Если владелец просит общий промт для двух моделей, делай один законченный
самостоятельный motion-бриф. Обе трактовки сохраняют исходный первый кадр,
личность, реквизит, композиционные якоря, одно главное действие и его конечное
состояние. Свобода — в темпе, пластике, выразительности, ракурсе или движении
камеры; не в подмене персонажа или сюжета. Допустимы совместимые альтернативы
операторского решения, но не несколько обязательных конкурирующих траекторий.
Естественное движение среды поддерживает главное действие, а не соперничает с ним.

Для серии выбирай режиссуру по функции шота: масштаб, крупность, оптика,
характер движения, ритм, смысловой или монтажный переход. Не повторяй
универсальный push-in/orbit во всех сценах, но сохраняй осознанные мотивы.
Эпик достигается физикой, постановкой, светом и контрастом, не обязательными
эффектами. Не выдумывай музыкальные таймкоды без выбранного аудио.
Пиши на языке, подходящем генератору (обычно английский).
Если задан числовой лимит, измерь длину всего отправляемого промта, включая
пробелы и переносы; учитывай более строгий предел интерфейса, если он известен.
Например, при запросе до 2500 с предпочтением до 2400 используй ориентир 2400,
не заполняя его искусственно. Это не универсальный лимит Arena.
Для рабочего 16:9 явно укажи TRUE 16:9 landscape, no letterboxing.

## 3. Нормализация существующих видео

По запросу на исправление формата сначала проверь геометрию, SAR и встроенные
полосы отдельно. Правильные ролики оставляй без перекодирования. Корректируй
только необходимое; сохраняй максимально близкое к исходному разрешение,
пропорции героя, длительность, кадры, частоту и звук. Не приводи всё к 720p
или 1080p ради одинаковых размеров; финальный экспорт — отдельная задача.
Дополнительный zoom/crop/stretch — только в рамках запроса; не путай небольшую
коррекцию пропорций с временной нарезкой. Значимое кадрирование проверяй визуально.

При разрешённой замене на месте используй временный выход и проверку до замены.
Сохраняй имена, не оставляй рабочих дублей; альтернативные генерации одной сцены
не являются дублями только по сюжету. SHA-256 доказывает лишь побайтовое равенство.
Массовая обработка на ПК — HEAVY по [корневому AGENTS](../../AGENTS.md);
admission, ресурсные проверки и лимиты действуют независимо от интерфейса.

## 4. Приёмка

Различай созданное видео, технически нормализованное видео и выбранный для
монтажа ролик. Проверяй фактический формат, полосы, длительность, кадры и
звуковые параметры, затем художественные свойства по [ANIMATION](ANIMATION.md).
Автоматическая выборка не заменяет просмотр. Не объявляй весь клип утверждённым,
если проверена только геометрия; честно укажи ограничения.
