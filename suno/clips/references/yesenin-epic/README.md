# Yesenin Epic — кураторские референсы

Небольшой версированный набор для **киношного современного AU-Есенина**, условно
«Рембо-Есенин»: охотник, экшен, корневое чудище и сильные эмоции.

Это **не универсальный Есенин для всех клипов**. Для лирических, камерных,
биографических или исторических работ сначала определи отдельный визуальный канон.
Не подменяй этим набором исторический портрет и не считай изображения документальными.

## Как применять

1. `identity-master.jpg` задаёт **лицо, возраст и причёску**, но не делает свой костюм
   обязательным для всех проектов.
2. Костюм — отдельная ось. Для «Что это такое?» нужен новый длинный тёмный плащ с высоким
   воротом; лицо из costume reference не должно заменять исходное лицо. См.
   [манифест проекта](../../projects/yesenin-chto-eto-takoe.md).
3. Для сложной мимики добавляй **один** подходящий expression reference как вторичный
   референс выражения, не как второго актёра.
4. Оружие, монстра и исходное дерево подключай только когда они нужны сцене. Двухружейный
   reference не означает два ружья в каждой ночной сцене: текущая серия «Что это такое?»
   использует одну винтовку с оптикой, а отдельная двухружейная линия сохраняется.
5. Обычно достаточно 1–3 референсов; явно назначь роль каждого в промте.
6. Референсы не отменяют требование финального 16:9. Некоторые исходники имеют другую
   пропорцию потому, что нужны для лица/мимики, а не как готовый кадр.

## Файлы

| Файл | Назначение |
|---|---|
| `identity-master.jpg` | Definitive лицо и причёска киношного AU-Есенина |
| `identity-face-close.jpg` | Крупный производный референс структуры лица; не новая личность |
| `expression-calm-alert-daylight.jpg` | Спокойная настороженность; также single-rifle reference без учёта костюма |
| `expression-startled-night.jpg` | Внезапная тревога, сдержанно раскрытый рот, ночь у дерева |
| `expression-tense-call-night.jpg` | Напряжённый возглас с более естественной челюстью |
| `expression-full-shout-night.jpg` | Сильный крик; использовать осторожно из-за риска деформации лица |
| `action-two-guns.jpg` | Двухружейная конфигурация только для отдельно согласованных шотов |
| `creature-root-giant.jpg` | Definitive анатомия и материалы корневого существа |
| `tree-origin.jpg` | Исходная обычная ель для формирования и обратного возврата |

Все expression-файлы — ранее выбранные пользователем удачные варианты. Набор намеренно
ограничен: невыбранные кандидаты, многочисленные retry и рабочие серии сюда не входят.
