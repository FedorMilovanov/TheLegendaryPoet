# Референсы Легендарного Поэта

Кураторский набор для повторного использования: силуэт, мантия, капюшон, синяя аура,
ворон и заднебоковая деталь костюма. Это **отдельный персонаж**, не identity-мастер
исторического Есенина и не AU-Есенин-охотник.

Статус на 2026-11-01: три небольших рабочих мастера собраны по запросу пользователя.
Полный горный силуэт был ранее выбран в Battle; два крупных плана присланы пользователем и
включены как costume/material references. Это не делает их фон, позу или действие общим
accepted-continuity. Файлы лежат в Git, а не во временной рабочей папке. Это не подтверждение
финального клипа, аудиомастера или прав публикации. Размеры ниже идентифицируют источники;
финальный кадр всё равно проверяется по 16:9 и отсутствию полос.

## Небольшой канон

- Длинная тяжёлая чёрная/почти чёрная мантия из слоёв реальной состаренной ткани;
  глубокий капюшон без читаемого лица и светящихся глаз; широкие плечевые слои, складки,
  потёртости, иней/снег по рельефу, неровный ветровой край. Не гладкий пластиковый плащ
  и не случайные доспехи без отдельного запроса.
- Эпичность создаётся силуэтом, масштабом, физикой ткани и светом, а не добавлением короны,
  гербов, оружия, неона или лишних аксессуаров.
- Обычно **один ворон**. Его посадка/полёт задаётся отдельно для шота; не копировать
  раскрытые крылья из ближнего мастера во все сцены.
- Холодная синяя аура — тонкие нити/контурное свечение и мягкий свет на ткани, снеге,
  камне или пергаменте. Она не должна скрывать крой и превращать ткань в неоновый пластик.
- Свиток/страница появляется только по сценарию. Новый читаемый текст не поручать модели;
  уже существующие знаки сохранять, если пользователь не просил их изменить.

## Как использовать в Arena

1. FIRST — base текущей композиции. SECOND — один подходящий мастер отсюда.
2. Для полного роста бери `mantle-full-body`; для ткани/ауры — `mantle-aura-raven`;
   для спины или ворона на плече — `mantle-back-raven`.
3. THIRD — второй вид Поэта только при реальной необходимости. Не загружать все три
   изображения по инерции: они передают разные ракурсы одного костюма, не три обязательных слоя.
4. Если локация новая, прямо написать «replace the background/location» и описать её.
   Мастер костюма не означает «сохранить гору, лес, луну и фоновых персонажей».
5. Для одного шота — один баттл. Для трёх разных шотов можно провести три независимых
   баттла с одним и тем же costume-reference; см. [playbook](../../ARENA_BATTLES.md).

Полный сценарный канон — в [CASE_LEGENDARY_POET.md](../../CASE_LEGENDARY_POET.md).
