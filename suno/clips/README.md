# Отдел SUNO-клипов для поэтов

Отдел превращает стихотворение и песню SUNO в последовательность отобранных кадров,
промтов оживления и готовый к монтажу визуальный пакет. Это отдельное направление:
музыкальные Lyrics, Style и произношение остаются в [SUNO-отделе](../README.md).

## Быстрый старт

Достаточно сказать: **«Работаем по `suno/clips`, делаем клип для …»**.

Агент читает [AGENT.md](./AGENT.md), затем проект из `suno/clips/projects/` или
ближайший профильный case. Если бриф неполный, используются правила отдела и
разумные defaults; анкета из лишних вопросов не нужна.

## Рабочая цепочка

1. **Исходник:** поэт, редакция текста, Lyrics-мастер и музыкальная концепция.
2. **Песня:** выбранный аудиомастер или явно обозначенный его черновик; длительность
   и тайминги не выдумываются без файла.
3. **Визуальный канон:** герой, эпоха/AU, костюм, реквизит, существа, свет и материалы.
4. **Раскадровка:** план кадров по смысловым частям песни, а не механически на каждый бит.
5. **Статичные кадры:** раунды ровно из трёх двухкандидатных баттлов на кадр/концепт.
6. **Отбор:** в производство идут только выбранные пользователем изображения.
7. **Оживление:** для выбранных кадров пишутся motion-промты; видео не считается
   созданным без фактически созданного файла.
8. **Монтаж и экспорт:** сверка с аудио, continuity, 16:9 и финальная проверка файлов.

## Правила по умолчанию

- Рабочий видеоформат — **16:9 landscape без letterbox**; финальный видеоэкспорт —
  1920×1080, если проект не задаёт другое.
- Не подменять утверждённого героя, существо или реквизит «похожим» вариантом.
- Не добавлять текст, логотипы и водяные знаки в изображения.
- Не смешивать рабочие кандидаты с каноном и не использовать отклонённые кадры как референсы.
- Не оживлять неотобранные изображения.
- Не переносить частный канон Есенина на других поэтов: для каждого клипа свой мир.
- Остановка пользователя прекращает генерации и автоматические повторы немедленно.

## Документы отдела

- [AGENT.md](./AGENT.md) — обязательный протокол работы и режим 3 баттлов.
- [VISUALS.md](./VISUALS.md) — референсы, промты, редактирование и визуальный QA.
- [ANIMATION.md](./ANIMATION.md) — промты оживления выбранных кадров.
- [STORAGE.md](./STORAGE.md) — MP3, изображения, видео, Git и рабочие файлы.
- [AUDIT.md](./AUDIT.md) — ошибки прошлых серий и постоянные меры против них.
- [PROJECT_TEMPLATE.md](./PROJECT_TEMPLATE.md) — шаблон манифеста нового клипа.
- [CASE_YESENIN_HUNTER.md](./CASE_YESENIN_HUNTER.md) — текущий канон Yesenin hunter.
- [references/yesenin-epic/](./references/yesenin-epic/README.md) — версированный набор
  киношного AU-Есенина и удачных выражений; только для подходящих эпичных клипов.

## Где лежат проекты и медиа

- Текстовые манифесты новых клипов: `suno/clips/projects/<poet>-<song>.md`.
- Небольшие утверждённые наборы мастеров: `suno/clips/references/<pack>/`.
- Промты и небольшая текстовая документация: внутри соответствующего проекта/каталога.
- Рабочие генерации в Arena: `image-search/<project>/`, пока не принято решение о выпуске.
- Финальные музыкальные мастера для публикации: `public/audio/` по
  [music release workflow](../../docs/MUSIC_RELEASE_WORKFLOW.md).

Не все рабочие изображения, MP3 и видео должны попадать в Git. Границы хранения —
в [STORAGE.md](./STORAGE.md).
