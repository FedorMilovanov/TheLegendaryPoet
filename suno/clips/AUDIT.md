# Аудит ошибок и постоянные правила

Это не архив чата, а только причины неудач и меры, применимые к следующим клипам.
Частные образы Есенина вынесены в [CASE_YESENIN_HUNTER.md](./CASE_YESENIN_HUNTER.md).

| Что пошло не так | Причина | Постоянное правило |
|---|---|---|
| Кадры приходили с широкими кинополосами вместо нужного видеоформата | «Cinematic» толковалось как 2.39:1 | Всегда писать `TRUE 16:9 LANDSCAPE, no letterboxing`; финал проверять по размерам |
| Пластиковый CGI и generic fantasy вместо live action | Недостаточно физических ограничений | Задавать материалы, вес, свет и поведение среды; запрещать plastic/rubber/CGI-look |
| Лицо героя менялось на другого актёра | Слабый или конкурирующий identity reference | Один definitive identity master; для лица допускается производный close-up |
| Исторический портрет начинал конкурировать с современным AU | Смешены разные режимы подлинности | Исторический источник не отменяет утверждённый современный мастер |
| Крик искажал челюсть, рот, щёки и сходство | Слишком широкая экранная эмоция | Делать анатомически сдержанный крик; личность и нормальная челюсть важнее ширины рта |
| Face-only правка меняла позу, оружие или фон | Свободное recreate вместо edit | Первым передавать base; одну зону менять, остальное явно сохранять |
| Состав и число оружия плыли между сценами | Глобальное правило не разделялось по сценам | В манифесте фиксировать реквизит и количество для каждой линии/шота |
| Монстр превращался в обычного tree man/demon | Не был закреплён definitive creature master | Использовать мастер анатомии и перечислять неизменные признаки |
| Пробуждение было то слишком незаметным, то сразу полным | Не были заданы границы стадии | Для каждой стадии писать, что уже произошло и чего ещё нет |
| Обратное превращение дало «супердерево» вместо исходной ели | Смешаны «стать деревом» и «вернуться в дерево» | Фиксировать физическую логику и исходный tree base; размер дерева не менять без брифа |
| Одиночные попытки вместо ожидаемых баттлов | Не был формализован режим | Стандартный раунд — ровно 3 баттла, каждый с двумя кандидатами |
| Отклонённые варианты могли считаться завершёнными | Статус зависел от вызова, а не выбора | `skipped` = rejected; accepted только после выбора и наличия файла |
| Прерванная генерация засчитывалась как попытка/результат | `aborted` смешивался с завершением | `aborted` не является accepted и не закрывает кадр |
| Повторы превращались в бесконечные одиночные циклы | Не было диагностики и правила остановки | Повтор — новый раунд из 3 с одной осмысленной поправкой; «хватит» останавливает всё |
| При outpaint 3:2 → 16:9 мог пострадать центр | Модель могла recreate/crop вместо дорисовки | Явно разделять outpaint и recreate; центр проверять, не заявлять pixel-perfect без проверки |
| Пользователь не мог найти выбранный файл | Глубокая техническая вложенность | Для выдачи открывать файл через `present_file`, при необходимости давать понятное имя |
| Вложение могло потеряться между сессиями | Источник оставался в `/tmp` | Сразу копировать рабочий источник в repository workspace |
| Слишком много референсов ухудшало управляемость | У изображений не было отдельных ролей | Обычно 1–3 референса; каждый имеет одну функцию и порядковое обозначение |
| Эпичность подменялась свечением и визуальным шумом | Не был задан источник масштаба/драмы | Сначала вес, география, свет и действие; свечение только по брифу |
| Нужен был быстрый переход к новым кадрам, агент продолжал ремонт старых | Приоритет последней команды не прерывал цикл | Новая команда «другие/дальше» отменяет старую очередь ремонтов |

## Что не копировать в новые клипы автоматически

- Ночной лес, корни и монстра — это конкретный мир Yesenin hunter, не шаблон каждого поэта.
- Два ружья, одна винтовка, костюм и современная внешность — только по проектному канону.
- Фотореализм и 16:9 являются текущими defaults отдела, но пользователь может задать иной
  художественный формат для нового клипа.
- Не переносить старые тайминги и эмоции на новую песню без анализа её реального аудио.

## Главный вывод

Качество серии определяется не числом генераций, а цепочкой:
**канон → понятная стадия → 3 баттла → явный выбор → проверка → только потом оживление**.
