# ARENA AGENT — Картинки

Работа с изображениями THE LEGENDARY POET в ChatGPT и LM Arena: идеи, промты,
генерация, правка, техническая подготовка и отбор. Это входной документ,
не второй визуальный канон и не инструкция по разработке сайта.

## 1. Контекст и режим

- Кадры клипа: [AGENT](AGENT.md), [VISUALS](VISUALS.md),
  [ARENA_BATTLES](ARENA_BATTLES.md) и нужный проект/кейс.
- Самостоятельная обложка, превью или постер: [covers/AGENT](../covers/AGENT.md).
- Файлы: [STORAGE](STORAGE.md); нагрузка ПК: [корневой AGENTS](../../AGENTS.md).
- Последняя конкретная просьба владельца определяет scope. Присланный им кадр
  можно использовать для заказанной работы без нового голосования; это не
  автоматическое утверждение общего канона.

Различай PROMPTS ONLY, GENERATE, EDIT, AUDIT, DELIVERY и техническую нормализацию.
Для каждого независимого кадра — самостоятельная художественная задача.
Число вариантов и баттлов определяют запрос и реальный режим интерфейса.
Не подменяй поиск файла или точный crop новой генерацией; не делай коллаж
вместо отдельных кадров. Сохраняй роли референсов и канон по профильным правилам.

## 2. Две рабочие среды

- **ChatGPT:** подготовь готовый к копированию промт либо выполни запрошенную
  операцию доступным инструментом. Для точных пиксельных операций используй
  обычную обработку изображений, не генеративную перерисовку. Работа на ПК —
  только через реально подключённый разрешённый инструмент.
- **LM Arena:** владелец может вручную загрузить референсы и промт, выбрать
  кандидата или скачать его. Если агент работает непосредственно в Arena,
  используй только фактически доступные инструменты и их лимиты.
- Передавай между средами исходное изображение, самостоятельный промт и,
  когда нужно, роль референса. Не считай, что файлы, история, выбор модели,
  голоса или пути автоматически синхронизируются. Не объявляй генерацию,
  передачу или выбор состоявшимися без доказательства.

## 3. Точное кадрирование без перерисовки

Если заказана только коррекция формата (например PNG до точного 16:9), измерь
исходник и выбери максимальный вписывающийся целочисленный кадр нужной пропорции.
Приоритет — заданная сторона обрезки и минимальная потеря площади, без resize,
растяжения, изменения цветов или генерации. Для 16:9 проверяй 9w = 16h.
Если точность требует небольшой обрезки другой стороны, укажи её; существенное
отклонение от запроса согласуй. При PNG проверь совпадение оставшихся пикселей
и сохрани применимые цветовые метаданные. По умолчанию сохраняй исходник.
При явной просьбе обновить именно этот файл допустима замена проверенным
временным результатом без постоянного дубля; не затрагивай другие мастера.

## 4. Приёмка

Фактические размеры, отсутствие полос, соответствие исходнику и художественная
проверка — по [VISUALS](VISUALS.md). Техническая готовность не равна выбору владельца.
В отчёте — что выполнено, где результат, что не проверено. Не выдавай
непринятый кандидат за канон. Для оживления переходи к [ARENA AGENT — Видео](ARENA_AGENT_VIDEO.md).
