# SUNO Quality Gate

Перед выдачей агент проходит все пункты. Один серьёзный провал означает переработку, а не примечание мелким шрифтом.

## A. Сохранность текста

- [ ] Каждое исходное слово сохранено либо изменение явно согласовано.
- [ ] Новые авторские строки не появились незаметно.
- [ ] Повторы состоят только из исходных слов и отмечены в редакторских решениях.
- [ ] Порядок строк не изменён без смысловой причины и пояснения.
- [ ] Авторская пунктуация и регистр не «улучшены» автоматически.

## B. Произношение

- [ ] Полностью выполнен `STRESS_PROTOCOL.md`; весь текст просканирован на омографы, редкости, имена и метрические конфликты.
- [ ] Все нормативные `ё` восстановлены по словарю/источнику, спорные имена не исправлены по догадке.
- [ ] До первой генерации отмечены только доказанные омографы/редкости/имена; обычные однозначные слова оставлены чистыми.
- [ ] Каждое поставленное ударение проверено в нужной словоформе и значении по профильному словарю.
- [ ] Для омографа, имени, варианта, архаизма или авторского отклонения есть второе независимое подтверждение.
- [ ] В редакторских решениях есть реестр каждого знака со ссылкой и статусом нормы.
- [ ] Рифма и метр не использованы как единственное доказательство переноса словесного ударения.
- [ ] Авторское/историческое ударение не «исправлено» под современную норму и не придумано агентом.
- [ ] Ни одного ударения над `ё`.
- [ ] Знак ударения — Unicode acute после гласной; капс/дефис/IPA не применены до фактической ошибки.
- [ ] Если источники не разрешили развилку, знак не поставлен, а риск сообщён честно.

## C. Драматургия Lyrics

- [ ] У песни есть различимые начало, перелом, кульминация и выход — либо осознанная антиформа.
- [ ] Секции следуют синтаксису и дыханию стихотворения.
- [ ] Главный повтор один и смыслово мотивирован.
- [ ] Whisper/echo не встречаются автоматически после каждой строфы.
- [ ] Теги короткие; внутри Lyrics нет производственных комментариев, которые могут быть спеты.
- [ ] Тишина и контраст используются наравне с громкостью.

## D. Качество Style

- [ ] Варианты отличаются аранжировкой, формой или пульсом, а не только эпитетами.
- [ ] В каждом Style понятны голос, ритм, инструменты, дуга и пространство.
- [ ] Нет взаимоисключающих указаний без временной последовательности.
- [ ] Эпический вариант не начинается сразу с максимальной громкости.
- [ ] Необычные инструменты имеют конкретную музыкальную функцию.
- [ ] Радикальный вариант остаётся уважительным к тексту и произносимым.
- [ ] Exclude Styles короток, конкретен и не отменяет основной замысел.
- [ ] Нет имён артистов и запросов на клонирование голоса.

## E. Практическая готовность

- [ ] Lyrics можно скопировать целиком без удаления пояснений.
- [ ] Канонический текст не подменён фонетической performance-копией.
- [ ] Каждый Style и Exclude можно скопировать отдельно.
- [ ] Один вариант явно рекомендован первым.
- [ ] Контрольная пара v6 запускается с `Variety = 0`; меняется одна переменная за итерацию.
- [ ] Max Mode предложен только для длинной песни/консистентности, v6-wild — отдельно для эксперимента.
- [ ] Даны критерии сравнения двух генераций, а не совет «выберите лучшую».
- [ ] Единичная ошибка направлена в single-lyric/section edit, а не в полную автоматическую переразметку.
- [ ] Remaster не предлагается для изменения Lyrics.
- [ ] Не выдуманы лимиты полей, «официальные» недокументированные теги или гарантия результата.
- [ ] При неизвестных правах есть краткое напоминание проверить их перед публикацией.

## Шкала внутренней оценки

Перед финалом оцени по 0–2: сохранность текста, произношение, драматургия, различимость вариантов, инструментальная логика, копируемость. Минимум для отметки `QUALITY GATE: пройден` — **11/12**, при этом сохранность текста и произношение обязаны получить по 2.
