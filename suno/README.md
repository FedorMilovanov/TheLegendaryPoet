# SUNO-отдел

Канонический набор инструкций для превращения присланного стихотворения в готовый пакет генерации для актуального интерфейса Suno.

## Как пользоваться

Достаточно дать агенту стихотворение и написать, например:

> Подготовь для SUNO. Текст не переписывай. Хочу несколько сильных трактовок.

Если дополнительных пожеланий нет, агент сам:

1. бережно нормализует `ё`;
2. поставит ударения **только там, где без них реально возможна ошибка**;
3. выстроит музыкальную драматургию и разметку секций;
4. добавит редкие, мотивированные whisper/echo/reprise-приёмы;
5. даст несколько существенно разных, готовых к вставке Style-вариантов;
6. выделит основной вариант, нестандартный вариант и вариант с необычными инструментами;
7. проведёт финальную самопроверку.

## Что читать агенту

- [`AGENT.md`](./AGENT.md) — главная обязательная инструкция и формат ответа;
- [`STRESS_PROTOCOL.md`](./STRESS_PROTOCOL.md) — строгий словарный протокол точечных ударений и авторских отклонений;
- [`QUALITY_GATE.md`](./QUALITY_GATE.md) — финальный контроль качества;
- [`RESEARCH_2026-10-15.md`](./RESEARCH_2026-10-15.md) — проверяемый пробег из 64 официальных, словарных и форумных источников;
- [`examples/GOOD.md`](./examples/GOOD.md) — хорошие примеры;
- [`examples/BAD.md`](./examples/BAD.md) — плохие решения и способы исправления;
- [`REQUEST_TEMPLATE.md`](./REQUEST_TEMPLATE.md) — необязательный расширенный бриф.

При конфликте документов приоритет имеет `AGENT.md`, затем `STRESS_PROTOCOL.md`, затем `QUALITY_GATE.md`.

## Важная граница

Этот отдел создаёт **творческое задание для генерации**, а не публикуемый музыкальный релиз. Готовый аудиофайл попадает на сайт только по правилам [`docs/MUSIC_RELEASE_WORKFLOW.md`](../docs/MUSIC_RELEASE_WORKFLOW.md): с проверенными правами, мастер-файлом, метаданными, checksum и остальными release-гейтами.

## Совместимость с актуальной Suno

По официальной документации, проверенной **15 октября 2026 года**, актуально семейство **Suno v6**: `v6-mini`, флагманский `v6` и экспериментальный `v6-wild`; прежние модели выведены из создания новых итераций. Инструкция использует устойчивые поля Custom-режима — `Lyrics`, `Style`, `Exclude` и доступные Advanced options — и отдельно учитывает v6 single-lyric edit, `Variety = 0` для контролируемого сравнения и Max Mode для длинных/требующих консистентности генераций.

Номер модели и интерфейс могут измениться, поэтому агент обязан сверяться с официальной документацией, а не переносить старые советы автоматически. Текущий evidence-срез и границы community-эвристик зафиксированы в [`RESEARCH_2026-10-15.md`](./RESEARCH_2026-10-15.md).
