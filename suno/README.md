# SUNO-отдел

Запрос: «Подготовь этот стих для Suno. Текст не переписывай» — достаточный бриф.
Агент читает [AGENT.md](./AGENT.md) и выдаёт Lyrics, музыкальные Style/Exclude,
редакторские решения и план запуска. При желании укажите голос, направление,
допустимые изменения или тариф; неизвестные предпочтения не блокируют ответ.

[Примеры и контрольные случаи](./CASES.md) показывают важные развилки.
Это не Suno API, не генератор аудио и не публикация песни на сайте.
Выпуск готового аудио регулирует [music release workflow](../docs/MUSIC_RELEASE_WORKFLOW.md).

## Проверки

- `npm run validate:suno` проверяет структуру комплекта и тесты счётчика.
- `printf '%s' "$STYLE" | npm run --silent check:suno-style` измеряет конкретный
  блок: пустой/пробельный или >1000 UTF-16 единиц отклоняется, >900 предупреждает.
- Ни один скрипт не оценивает музыкальную красоту, произношение, истинность
  словарной ссылки или фактическую сохранность нового Lyrics. Это отдельно
  проверяют агент и человек, после генерации — также на слух.

## Происхождение и перенос

Выборочный переработанный перенос из
[`8ccd5ff1`](https://github.com/FedorMilovanov/TheLegendaryPoet/tree/8ccd5ff1c17e2311ff4b030f4b26113b8073a69f/suno),
ветка `arena/67623931-thelegendarypoet`. Старый runtime, package.json и AGENTS.md
не импортированы. Устранены разные разрешения на перестановку строк, лишние
ударения и отрицательный Style в примерах, недоказанная историческая категоричность
и самооценка «13/14» как допуск.

Старые датированные research/audit-файлы сохранены по ссылке как происхождение,
не как независимо перепроверенные 67 источников или обязательное чтение на каждый стих.
Новый владелец инструкции — этот каталог, маршрут к нему — корневой AGENTS.md.
Rollback: убрать routing, npm-команды/гейт и каталог со скриптами/тестами вместе;
это не влияет на runtime сайта и не требует удаления исследовательской ветки.
