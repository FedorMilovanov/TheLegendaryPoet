# COVER ART DEPARTMENT — рабочий протокол

Владелец: The Legendary Poet / художественная редакция. Область: музыкальные обложки, YouTube thumbnails, релизные иллюстрации, новогодние и несезонные серии. Это не отдел клипов и не разрешение на публикацию. Правила ниже — первоначальная редакция, уточняемая по реально выбранным работам владельца.

## 1. До любого запуска

- Сначала определить режим: RESEARCH / PROMPTS ONLY / GENERATE / EDIT / QA / RELEASE HANDOFF. Исследование и промпты не разрешают запуск генерации. Не тратить дополнительные кредиты, не заменять, не публиковать файлы без заказа.
- Установить точную композицию: автор, произведение/MASTER, выбранная версия, фактические Lyrics и Style, предназначение обложки, формат, буквальный текст, число вариантов. Suno read-only по WORKBENCH; название, лайк, Style и текст не доказывают прослушивание и финальный выбор аудио. Приватные ID и тексты закрытых работ не помещать в публичный git.
- Прочитать канон персонажа, актуальные утверждённые референсы владельца, последние замечания и опубликованные обложки. Смотреть сами пиксели, не ограничиваться названиями. Не использовать брак предыдущего раунда как референс. Историческое лицо — только по соответствующему портретному мастеру и проверенным историческим изображениям; не подменять случайным красавцем.
- Для новой серии провести содержательный сравнительный поиск: портреты/эпоха, кино key art, музыкальное оформление, типографика, платформенные требования. Для глубокого аудита по заказу владельца — 30+ разных URL, отмечать найденные/прочитанные/визуально просмотренные отдельно; не считать зеркала и вариации URL отдельными источниками. Не имитировать чужие макеты и чужую айдентику; извлекать принципы. Для повторной работы использовать накопленный реестр, не делать ритуальный поиск.
- До генерации подготовить раздельные арт-дирекции и полностью сформулированные промпты, затем проверить их на разнообразие и соответствие канону. Нельзя начинать с первой попавшейся идеи. Продолжительность размышления сама по себе не показатель качества.

## 2. Визуальный канон и свобода

- Основной уровень — премиальный кинофотографический реализм, оптика, физически правдоподобный свет, фактура, пластика, пространство, эмоциональная выразительность. Не гладкий CGI, не пластиковая кожа, не декоративная AI-открытка. По материалу допустимы сознательные графические, редакционные, концертные и символические направления; обозначать недокументальные сцены.
- Брендовый синий — узнаваемый акцент, не заливка всей сцены. Допустимы тёплые практические источники, естественный снег, дневной свет, цветовые контрапункты. Не навязывать ночную метель, луну, северное сияние, электрические кольца, горы, ворона или симметрию каждому варианту.
- Легендарный Поэт — самостоятельный необязательный персонаж. Если используется, читать [его кейс](../clips/CASE_LEGENDARY_POET.md) и смотреть [мастера](../clips/references/legendary-poet/README.md): глубокий чёрный капюшон без лица, тяжёлая состаренная ткань, естественный силуэт, синий свет по ситуации. Не путать с историческим поэтом. Ворон опционален. Новогодний головной убор только как осознанная вариация, не раскрывать лицо.
- Исторические поэты: отдельный identity reference каждого автора, конкретный возраст и эпоха. Не омолаживать без основания; не переносить лицо одного автора на другого. Современная сцена допустима как AU, но не выдаётся за историческую реконструкцию.
- Новогодние обложки — не одинаковая серия открыток. Праздник может выражаться через свет, танец, полночь, снег, костюм, архитектуру, концерт, предмет или цвет. Связь с конкретным текстом/музыкой важнее обязательной ёлки.
- Явный отказ владельца 2026-11-25: случайный молодой мужчина вместо Фета, пять одинаковых синих горных пейзажей, глянцевая фэнтези-эстетика, серебряно-хромированные буквы, перья-завитушки, разделительные полосы, снежинки/камни/декоративные подвески под логотипом. Не возрождать эти решения. Это не запрет на реальные камни как часть естественного пейзажа.

## 3. Типографика и форматы

Варианты: TITLE + AUTHOR + BRAND, BRAND ONLY, TITLE ONLY, CLEAN ART (без текста). Выбирать по задаче, не добавлять всё автоматически. Брендовая надпись THE LEGENDARY POET (или явно заказанная русская) — синий, чистый силуэт букв, контролируемый контраст, без псевдокристаллов, завитков, перьев, лишних линий, орнаментального подчёркивания и свечения, размывающего буквы. Официальный знак — только действующий утверждённый asset из корневого AGENTS; генератор не должен сам рисовать новый логотип. Если текст нужен в картинке, указать точное написание, язык, иерархию, свободную область и расположение. Лучше чистый мастер плюс отдельный типографический слой, если генератор ошибается; не маскировать ошибки. Не помещать техническое название варианта Suno, TOP, BPM и версии на релизную обложку без указания.

- YouTube longform: 16:9; рабочий целевой экспорт 3840×2160 если реально доступен; проверять актуальный лимит и кодек при выпуске, допустимый меньший нативный размер не объявлять 4K. Проверка 320×180 и 160×90; лицо/силуэт и основной заголовок читаемы, не перекрыты бейджем длительности справа снизу. Без letterbox, растяжения и несанкционированной обрезки.
- Square / Suno / музыкальные платформы: отдельная 1:1 композиция, проверять реальные требования целевого сервиса. Для вертикали — отдельный 9:16 кадр. Не превращать 16:9 в квадрат обрезкой лица; не считать upscale нативным качеством.
- Рабочая гипотеза для YouTube: один визуальный центр и один главный текстовый блок; проверка на маленьком превью, реальные расстояния и контраст, минимум вторичного текста. Не обязательный шаблон расположения. YouTube A/B — три реально разных кандидата по актуальным правилам, только с разрешением на изменение публикации.

## 4. Независимые генерации — антиколлажный контракт

N вариантов = N независимых арт-брифов, N отдельных заданий с одним цельным изображением на задание. В каждом промпте явно указать: ONE standalone image; one continuous scene; no collage, grid, contact sheet, diptych, triptych, panels, mockup, comparisons, borders or multiple covers inside the frame. Не передавать общий запрос «10 обложек» в один вызов с ожиданием десяти различных концепций. API n=10 для одного prompt — не десять отдельных промптов. Для API — N отдельных request payloads, n=1, по возможности независимый контекст, только нужные референсы, отдельная учётная запись результата; параллелизм лишь в разрешённых лимитах. Для ChatGPT — N отдельных одноизображенческих вызовов только если интерфейс реально поддерживает; если нет, честно указать фактическое число и остаток, не подменять коллажем/повторной генерацией и не гарантировать 10 в одном ответе. Не выдумывать доступ к API или ключу. Репозиторий не меняет ограничения инструментов.

Каждый промпт содержит: конкретный смысл трека; композицию и пространственный план; действие, героя и роли референсов; оптику/свет/материалы; настроение и цвет; точный режим надписей; самостоятельный формат; исключения. Длина определяется полнотой, а не количеством прилагательных. В большом пакете проверить матрицу: разные локации, масштабы, ракурс, действие, свет, цветовая логика, субъект и типографика. Должны различаться минимум по нескольким существенным художественным параметрам, не просто позой, фильтром и цветом одной сцены. Не скармливать кандидат предыдущей генерации следующему без явной задачи continuity. Если референс переносит старую композицию, использовать только identity crop или указать его ограниченную роль.

## 5. Приёмка

На каждый кандидат: ID задачи, exact prompt, роли ссылок, фактический инструмент/размер, статус DRAFT/REJECTED/OWNER_SELECTED, наблюдаемые дефекты, причина выбора. Не считать красивое описание доказательством изображения. Проверить фактические пиксели: единая сцена, правильные пропорции, лицо/возраст, анатомия/руки, физика света и материалов, отсутствие водяных знаков и мусора, правильность надписей включая Ё, читаемость thumbnail, отличие от других кандидатов. Неверный автор, коллаж, ошибочный заголовок, раскрытый капюшон, нарушенный формат или явный брак — HOLD/REJECT, а не косметическая самооценка. Не повторять платные вызовы автоматически. Художественное принятие только по явному выбору владельца; технический PASS не равен премиальному виду. Не публиковать и не переписывать существующие обложки по одному техническому PASS. После выбора — отдельный handoff по release workflow, права, metadata и площадки.

Разработай N действительно независимых премиальных концепций и полный отдельный промпт для каждой. Режим [PROMPTS ONLY / GENERATE], формат [16:9 / 1:1 / 9:16], текст [title/brand/clean]. При GENERATE сделай N отдельных работ, не коллаж; сначала проверь план, затем результаты. Никакой публикации. Не считать невыбранные результаты каноном.»
