# Необязательный бриф для SUNO

Стихотворения достаточно. Этот шаблон нужен только тогда, когда хочется точнее управлять результатом.

```text
ТЕКСТ:
[вставить стихотворение без предварительной разметки]

ОБЯЗАТЕЛЬНО СОХРАНИТЬ:
[слова / пунктуацию / порядок строф / конкретное произношение]

ДОПУСТИМЫЕ ИЗМЕНЕНИЯ:
[только ё и ударения / повторы исходных строк / перестановка / новый припев]

ГОЛОС:
[не задан / женский / мужской / андрогинный / дуэт / хор; тембр и регистр]

ЖЕЛАЕМАЯ ДУГА:
[камерно → катастрофа → тишина]

ЖАНРЫ ИЛИ ОБРАЗЫ:
[необязательно]

ЧЕГО ИЗБЕГАТЬ:
[эстрадность, трейлерность, EDM-drop, чрезмерное вибрато и т. п.]

ПРАВА / АВТОР:
[собственный текст / общественное достояние / разрешение есть / неизвестно]
```

Не нужно заполнять неизвестные пункты. Агент не должен повторно спрашивать то, что уже следует из текста или запроса.
