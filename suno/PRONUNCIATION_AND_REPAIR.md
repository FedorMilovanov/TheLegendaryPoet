# Точная дикция: исследование → минимальная правка → проверка

Дополнение к [AGENT](./AGENT.md), не второй владелец правил.
Для архаизмов, омографов, е/ё, спорного ударения или ремонта ошибки Suno
прочитай этот протокол **до** внесения знаков. Обоснования и пределы исследования:
[реестр 2026-10-25](./RESEARCH_2026-10-25.md).

## 1. Раздели три объекта

- **Исходник**: неизменная присланная редакция, включая авторские знаки.
- **Lyrics-мастер**: только разрешённые и раскрытые отличия от исходника.
- **Performance-копия**: локальная экспериментальная запись для услышанной ошибки.
  Не подменяет мастер, не восстанавливается из памяти; версионируй её diff.

Не удаляй диакритику «очисткой Unicode». Не превращай кириллическую `о` в
латинскую `ó`: похожая картинка не тот же символ. Для русского — гласная + U+0301.
Не меняй исходную `й`/`ё` через удаление всех combining marks после NFD.
Проверка совпадения слов не доказывает правильности ударения.

## 2. Карточка рискованного места

На каждое реальное вмешательство, не на каждое слово:

`строка → исходная форма → значение/морфология → предлагаемая запись →
тип нормы (современная/вариант/историческая/неясно) → источники с изданиями →
независимость → зачем знак → уверенность/нерешённое → точный diff`.

1. Сначала установи контекст: омографы `за́мок/замо́к`, падеж/число, отрицание,
   имя собственное. Значение не угадывать по одному слову.
2. Ищи **эту словоформу и значение**, а не только лемму или общую статью про ё.
3. Для современного чтения: профильный орфоэпический словарь, орфографический
   для написания; фиксируй пометы «допустимо», «устар.», «проф.», а не стирай их.
4. Для исторического: академический комментарий/словарь эпохи/авторский знак;
   исследуй дату текста и автора. Современный словарь здесь лишь контраст.
5. Два зеркала одного словаря не независимы. Две страницы одного форумного автора
   тоже не два подтверждения. Число источников не разрешает конфликт автоматически.
6. Если доступна только поисковая выдержка, это указатель для проверки, не
   прочитанная статья и не достаточное основание спорной правки.
7. При нехватке доказательств оставь исходное написание и обозначь развилку.
   Один конкретный вопрос нужен только если выбор меняет смысл/дальнейшую работу.

### Ловушки словарей и корпуса

- Зарва сознательно выбирает один предпочтительный вариант. Отсутствие другого
  не равняется запрету; проверь издание и политику словаря.
- НКРЯ использует гравис для **икта**; словарь может использовать его для побочного
  ударения. Значение знака устанавливай по легенде конкретного источника.
  Никогда не конвертируй все грависы в акуты автоматически.
- Авторазметка и статистика поэтического корпуса не нормативный словарь.
  Метрическая позиция отдельного вхождения не доказывает произношение слова.
- Не выдумывай «старинное» ударение, чтобы получить ровный ямб. Перебои,
  пропуски схемного ударения и смешанные размеры не баг авторского текста.
- Рифма с е не доказывает, что любое е этой эпохи надо читать без ё, и наоборот.
  Исходная орфография сама по себе не фонетическая транскрипция.
- Повреждённые диакритики PDF/OCR проверяй по изображению страницы или другому
  надёжному представлению. Нет доступа — не восстанавливай знак по догадке.

## 3. Диагностика услышанной ошибки, не ритуал тегов

Сначала получи аудио или конкретное описание с таймкодом; без аудио обозначь
диагноз гипотезой. Раздели: неверное словесное ударение / вокальная артикуляция /
языковой дрейф / пропущенное слово / лишняя строка / рассинхрон displayed lyrics.

| Симптом | Первое обратимое действие | Что не обещать |
| --- | --- | --- |
| Ошибка одного слова | Локальный Edit Lyrics/доступный редактор; сохранить исходный трек | Сохранение голоса, мелодии и стыка без прослушивания |
| Подпись не совпадает с вокалом | Проверить waveform и привязку; отдельно исправить отображаемый текст | Что редактирование подписи изменило аудио |
| Спета режиссура | Убрать длинную инструкцию из Lyrics, перенести слышимый признак в Style | Что любые квадратные скобки гарантированно не споются |
| Растянуты слоги, «сбит» акцент | Проверить темп/дыхание/плотность аранжировки, затем одну переменную | Право сокращать стих или переносить словесное ударение |
| Дрейф языка | Отдельно испытать явную языковую подсказку при неизменном остальном | Что Russian/Slavic улучшает только дикцию |

Фонетика, капс, дефисы, апострофы и Cover из форумов — только локальные гипотезы
после ошибки, не обязательная предварительная обработка. Не менять сразу и
написание, и голос, и темп. Не переносить чужой процент успеха на свой материал.
Не обходить отказ по правам фонетической маскировкой; выяснить основание отказа.
Не включать платные режимы и новые зависимости без нужного разрешения.

## 4. Карточка эксперимента и условия остановки

`модель/дата/UI/доступные параметры → исходный фрагмент/таймкод → гипотеза →
единственное изменение → варианты аудио → услышанный результат → новые дефекты`.

Текст/аудио/метаданные храни раздельно; не считай совпавшую подпись доказательством.
Сравни слова, дикцию, соседние фразы, голос, ритм, переходы и конец композиции.
ASR — вспомогательная расшифровка, не судья ударений и не замена русскому слуху.
Если два сопоставимых теста подряд не подтверждают гипотезу, не расходуй кредиты
дальше автоматически: предложи другой локальный путь или запроси решение владельца.
Это внутренний лимит осторожности, не статистический тест качества Suno.

## 5. Последняя проверка до выдачи

- Сверить каждую строку; раскрыть добавленные ё/акуты, повторы и теги отдельно.
- Не прятать самопроверку фразой «всё сохранено»: назвать инструмент или ручной diff.
- Проверить каждый финальный Style счётчиком, Exclude оставить отдельным полем.
- Формулировка вывода: **проверено по тексту / подтверждено источником /
  требует аудиопроверки / не установлено**. Не заменять её единым баллом качества.
