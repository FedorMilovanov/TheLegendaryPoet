## Приоритетная новая кандидатура

- Первичный литературный источник: https://rvb.ru/20vek/blok/pss20/vol3/text/0548.html.
- Соединяемая по смыслу работа — «О, я хочу безумно жить…» (1914): https://rvb.ru/20vek/blok/pss20/vol3/text/0593.html. Это **другой текст** и не основание автоматически добавлять его строки или объявлять один и тот же трек двумя композициями.
- Межплатформенный выпускной реестр: `FedorMilovanov/video-channel-manager/content/editorial/legendary-poet/blok-night-two-realities-20261114.release.json`.
- Провести поиск исходника в исходном проекте Suno, скачанных экспортах и локальных рабочих пакетах. Сопоставить полноценные версии, а не извлекать звук из первого встретившегося рендера.
- Если в видео есть уникальная, ценная музыкальная версия, допускается отдельный `video-extraction` кандидат, **только** при подтверждённых проектных правах, точном происхождении и итоговом прослушивании; не смешивать с основным мастером.

## Для каждого последующего релиза

1. **Discovery:** перечислить все проверенные оригиналы, варианты Suno, экспортированные WAV/FLAC/MP3 и сопровождающие клипы, не полагаясь на заголовки YouTube как на инвентарь музыки.
2. **Binding:** SHA-256 и точное происхождение файла, наименование автора/произведения и конкретной версии, без автоматической подмены удачного музыкального дубля.
3. **Audition:** весь звук плюс прицельная проверка начала/конца, переходов и неожиданных добавок; подозрительные паузы — на прослушивание, не на автообрезку.
4. **Master selection:** утверждённый один мастер на release ID; при обработке — сохранить исходный и итоговый SHA; записать характер обработки.
5. **Release:** отдельный MP3 для сайта по уже действующей схеме (обложки, waveform, manifest, права, дата, `published` только после загрузки); WAV/FLAC остаётся архивной мастер-копией.
6. **Distribution:** Telegram `sendAudio` получает **утверждённый аудиомастер/экспорт**, а не конвертированный YouTube-стрим; VK, Instagram и YouTube получают собственные пригодные для этих платформ медиаверсии. В каждой платформе — отдельный provider-readback без дублей.
7. **Postflight:** реальный публичный URL и воспроизведение сайта, фактическая длительность, метаданные и закреплённая связь с источниковой карточкой стихотворения.

Нет подтверждённого исходника → нет нового `published` аудиотрека. Нет подтверждения отсутствия публикации → нет повторного POST.

Проверка одного найденного файла:

```bash
node scripts/audit-audio-candidate.mjs "/path/to/master.wav" --origin suno-export
```
