## Remaining moderate advisories

Two React Router advisories remain in the package scanner:

1. an open-redirect class involving backslashes in `Link` or `useNavigate` destinations;
2. constructor injection in the SSR hydration `deserializeErrors()` path.

They are not silently ignored. The application now enforces an executable compensating boundary:

- all internal `Link`, `NavLink` and imperative navigation pass through `src/components/ui/Link.tsx`;
- backslashes, protocol-relative destinations and absolute URL schemes are rejected before routing;
- direct `Link` / `NavLink` / `useNavigate` imports outside the canonical wrapper are forbidden;
- SSR router hydration APIs, including `deserializeErrors`, are forbidden in this client-only SPA;
- `scripts/validate-router-security.ts` is part of `check:content` and fails closed if this architecture regresses.
