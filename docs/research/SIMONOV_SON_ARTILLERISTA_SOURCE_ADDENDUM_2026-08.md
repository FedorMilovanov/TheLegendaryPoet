# «Сын артиллериста» — source addendum после 40-source ledger

Дата прохода: 2026-08-18  
Статус: **second-pass addendum / does not mutate the closed 40-row ledger**

## Зачем отдельный addendum

Первый 40-source ledger был сознательно зафиксирован как закрытый исследовательский раунд и уже используется staged-validator'ом как стабильный baseline. Последующая работа дала несколько новых источников и, что важнее, **точных object locators**. Вместо бесконечного переписывания первоначального списка этот файл фиксирует второй слой provenance.

Правило остаётся прежним: наличие точного locator ещё не равно прямому просмотру объекта; вторичная публикация, цитирующая архив, не становится архивом автоматически.

**Уровень:** A+ institutional digital corpus  
**Root:** https://elib.shpl.ru/ru/nodes/25135-krasnaya-zvezda-tsentralnyy-organ-ministerstva-oborony-rossiyskoy-federatsii-m-1924-ezhedn

### Значение

### Техническая опора

Документация ГПИБ подтверждает поиск по полным текстам документов при наличии OCR. Архив обновлений фиксирует добавление `Красной звезды` за 1941 год в электронную коллекцию во второй половине июня 2017 года.

### Ограничение

Exact child-node ID № 288 и страница/колонка `Сына артиллериста` в текущем проходе **не обнаружены напрямую**. Node ID нельзя вычислять по соседним значениям. Статус: `complete corpus verified / exact issue node and poem page pending`.

## Второй раунд: source hierarchy после addendum

Для будущего prose pass приоритет должен быть таким:

1. direct scan record `10800112`, если визуально подтверждён;
2. письмо Лоскутова 03.03.1966 в проверенном печатном/архивном witness;
3. авторский дневник/комментарий Симонова;
4. direct newspaper objects 1941 и 1966 — для `Красной звезды` приоритетный текущий route теперь ГПИБ/SHPL;
5. ЦАМО/Pamyat records по Рыклису и другим service facts;
6. институциональные региональные архивы/библиотеки;
7. музейные item records;
8. качественные media delivery copies;
9. popular/encyclopedic navigation only as search leads.

Главный принцип: **direct object supersedes locator, locator supersedes unsourced repetition, но источники разных жанров не “сливаются” в один голос.**
