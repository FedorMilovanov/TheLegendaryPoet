# Fact-check checklist for reader-facing longform

## Claim integrity

- [ ] Every date with a day/month is supported by a direct or academic source.
- [ ] Approximate dates remain approximate in prose.
- [ ] A memoir is named as a memoir at first load-bearing use.
- [ ] A quotation was checked against the page or official text, not a quotation site.
- [ ] The speaker, recipient, edition and date are not conflated.
- [ ] An archive-card description is not presented as if the full file was read.
- [ ] A typescript copy is not called an autograph.
- [ ] A facsimile in a later scholarly publication is not silently upgraded to the original archive object.
- [ ] A catalogue result is not treated as a downloaded and page-verified object.

## Causality

- [ ] No death, rupture, addiction or conversion is explained by one convenient cause.
- [ ] Language such as «погубила», «сломала», «довела» or «спасла» is supported or removed.
- [ ] A poem is not used as a complete medical or political confession.
- [ ] A diagnosis is not inferred from a portrait, style or temperament.
- [ ] Context explains without excusing.
- [ ] Human agency is not erased by epoch, illness, partner or audience.

## Moral and biblical assessment

- [ ] The documented action is stated before the moral classification.
- [ ] The classification does not invent an unrecorded motive.
- [ ] Compassion does not rename sin as virtue.
- [ ] Sin is not aestheticized as the source of genius.
- [ ] Religious imagery is not called saving faith without evidence.
- [ ] A possible unknown final moment is not presented as a historical version.
- [ ] The text does not claim access to God’s final judgment beyond Scripture’s general teaching.
- [ ] The reflection speaks to the reader and points to Christ rather than using the subject as a moral specimen.
- [ ] The article still works as history if the reflection block is read separately.

## Myth control

- [ ] Each famous anecdote has a traceable witness.
- [ ] Late recollections are checked against chronology.
- [ ] Contradictory versions are not combined into one cinematic scene.
- [ ] «Everyone knew», «nobody came», «last words» and exact dialogues receive special scrutiny.
- [ ] Rejected myths are not reintroduced in card copy, SEO, captions or VK previews.

## Visual integrity

- [ ] Identity is checked.
- [ ] Date and place are not guessed from appearance.
- [ ] The image depicts what the caption says.
- [ ] Item-level rights and credit are stored.
- [ ] Generated or restored images have the correct `kind`.
- [ ] A document is readable in lightbox.
- [ ] Placement has a narrative function.
- [ ] Mobile crop preserves faces and document content.
- [ ] No image is used merely because it was already in Drive.

## Publication

- [ ] Source IDs resolve.
- [ ] No duplicate source URLs.
- [ ] Cover provenance and SHA are current.
- [ ] `dateModified` reflects a substantive change only.
- [ ] Sitemap, feed, prerender and Open Graph use the correct image.
- [ ] Desktop, Android Chrome and iPhone Safari checks passed.
- [ ] The VK announcement does not overstate the article.
- [ ] Unknown API outcomes are reconciled without blind retry.
