## 3. Какие страницы нужны для direct collation

Приоритетные печатные страницы по библиографии ПКДБ:

- **с. 393** — ранний контекст/упоминание, связанное с поэмой;
- **с. 430–433** — основной поздний авторский рассказ о прототипе.

На этих страницах нужно визуально проверить, в частности:

- точную формулу о том, что реальную фамилию лейтенанта Симонов тогда не записал;
- `Лёнька`, `Деев`, `Петров` как литературные имена;
- авторское объяснение выбора фамилий для стихотворного размера;
- chronology 1964 → встреча → письмо 1966;
- формулировку о судьбе отца прототипа;
- **точное имя отца в печатном тексте** — критично для конфликта `Иван Михайлович / Алексей Михайлович`.

## 4. Почему pages пока не считаются inspected

В текущем toolchain:

- поисковый web index уверенно видит HTML-страницу и exact file links;
- попытка открыть PDF ZIP через web tool вернула `Cache miss`;
- попытка скачать тот же exact URL через container environment завершилась DNS/network failure для `publ.lib.ru`.

Следовательно, **это access limitation текущего инструмента, а не отсутствие scan**.

Редакция не имеет права писать, что страницы 393 / 430–433 уже просмотрены, только потому что файл найден.

Текущий статус:

**exact scan located / bytes not acquired / relevant pages uninspected.**
