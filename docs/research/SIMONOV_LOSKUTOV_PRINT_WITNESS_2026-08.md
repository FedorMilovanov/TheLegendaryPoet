## Claim boundary

Из опубликованной передачи допустимо использовать с явной источниковой дисциплиной:

- июль 1941 года без точного числа;
- лейтенант / командир взвода топографической разведки;
- радиостанция + два разведчика + пехотный проводник;
- примерно три километра в позднем письме;
- туман, пулемётно-миномётный огонь, движение преимущественно ползком;
- наблюдаемые цели и передачу координат;
- повторную команду открыть огонь непосредственно по высоте;
- выживание группы, разбитую радиостанцию, уход под туманом;
- возвращение в часть, где группу считали погибшей.

Не выводим без direct witness:

- точный календарный день боя;
- `шесть суток`;
- точную высоту/координаты;
- внутренние мысли Лоскутова;
- личность человека на КП, который переспросил команду.
