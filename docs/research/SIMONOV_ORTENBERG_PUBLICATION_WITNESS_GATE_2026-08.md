# Симонов → Ортенберг → «Красная звезда» — publication witness gate

Дата прохода: 2026-08-18  
Статус: **author handoff verified in Simonov retrospective / Ortenberg quote independently transmitted but exact original locus pending**

## Зачем этот gate

Для истории первой центральной публикации `Сына артиллериста` есть две близкие, но методологически разные линии:

1. **Симонов сам** вспоминает, как после приезда в Москву прочёл поэму редактору `Красной звезды` Давиду Ортенбергу и она сразу пошла в номер.
2. Приморская краевая детская библиотека приводит **воспоминание Ортенберга** с более зрительной сценой: Симонов достаёт исписанные листы, читает поэму, а редактор пишет на первой странице `В номер`.

В массовом пересказе эти два свидетельства легко сливаются. Серьёзная статья должна хранить их отдельно, пока exact original Ортенберга не локализован.

---

## 1. Симонов: прямой author witness редакционной передачи

В доступной электронной передаче главы 19 `Разных дней войны` Симонов даёт внутренне связанную хронологию:

- 28 ноября 1941 — Архангельск / Соломбала;
- во время задержки в Архангельске написан `Сын артиллериста` за одни сутки;
- 5 декабря утром поезд находится в Александрове;
- затем Симонов приезжает на Ярославский вокзал в Москве;
- среди ночи появляется Давид Ортенберг;
- Симонов читает ему `Сына артиллериста` вслух;
- по авторской формуле, поэма **сразу пошла в номер**.

Источник:
https://militera.lib.ru/db/simonov_km/1_19.html

### Сила

Это **author retrospective**: очень сильный источник для того, что Симонов помнил о передаче текста редактору. Он не заменяет газетную полосу, но отлично связывает архангельское написание с выпуском `Красной звезды` 7 декабря.

### Production-safe wording

> После возвращения в Москву Симонов, по собственному воспоминанию, прочёл поэму редактору `Красной звезды` Давиду Ортенбергу; текст сразу пошёл в номер.

Эту формулу можно использовать уже сейчас с sourceId авторского дневника.

## 2. Ортенберг: сцена с надписью «В номер»

Государственная `Приморская краевая детская библиотека` в издании `Кто он, Лёнька Петров?` приводит воспоминание Давида Иосифовича Ортенберга:

- Симонов только что вернулся с Северного фронта;
- во время разговора предложил прочитать стихи;
- достал из полевой сумки исписанные листы;
- прочёл поэму вслух;
- Ортенберг после чтения написал на первой странице рукописи **`В номер`**.

URL:
https://www.pkdb.net/nashi-izdaniya/item/42-kto-on-ljonka-petrov.html

Библиография страницы указывает для этого фрагмента:

`Воспоминания Давида Иосифовича Ортенберга, ответственного редактора газеты «Красная звезда» // http://thefireofthewar.ru`.

### Что закрыто

Закрыто наличие **институциональной вторичной передачи**, которая явно атрибутирует сцену Ортенбергу.

### Что НЕ закрыто

Пока не найден exact original locus:

- название книги/статьи/главы Ортенберга, из которой взят именно этот фрагмент;
- печатная страница;
- прямой электронный URL на этот конкретный фрагмент на `thefireofthewar.ru`;
- manuscript/facsimile с самой надписью `В номер`.

Поэтому THE LEGENDARY POET **не пишет, что рукопись с автографом `В номер` непосредственно просмотрена**.

## 3. Книга Ортенберга 1984: существует, но quote locus не доказан

Отдельно подтверждено существование мемуарной книги:

**Д. И. Ортенберг. `Июнь — декабрь сорок первого: Рассказ-хроника`. — М.: Советский писатель, 1984. — 352 с.**

Доступная библиографическая/электронная authority:
https://militera.lib.ru/memo/russian/ortenberg_di1/index.html

Militera прямо указывает издание 1984 года, объём и OCR-происхождение электронной версии.

### Важная граница

Текущий поиск **не локализовал в этой книге exact phrase** `Симонов только вчера вернулся... / написал: В номер`.

Следовательно, нельзя просто переписать библиографию ПКДБ как:

> `Ортенберг, Июнь—декабрь сорок первого, 1984, стр. X`

без найденной страницы.

Возможно, воспоминание находится в другой публикации Ортенберга или отдельной компиляции. Это остаётся research target.

## 4. Как соотносятся Симонов и Ортенберг

Даже без exact Ortenberg locus два свидетельства не противоречат друг другу:

- Симонов: прочитал Ортенбергу → поэма сразу пошла в номер;
- институциональная передача Ортенберга: прочитал → редактор написал `В номер`.

Но совпадение содержания **не даёт права объявить вторую реплику первично проверенной**.

Для production narrative controlling source сейчас — **Симонов**. Ортенберговская сцена может использоваться только как secondary corroboration либо после exact-locus closure.

## 5. Поисковые маршруты для closure

- [ ] direct-search полного текста `Июнь—декабрь сорок первого` по фразам `Сын артиллериста`, `только вчера вернулся`, `В номер`, `исписанных листиков`;
- [ ] проверить книги Ортенберга `Время не властно`, `Это останется навсегда`, возможные сборники воспоминаний о Симонове;
- [ ] проверить `Константин Симонов в воспоминаниях современников` (М.: Советский писатель, 1984) на воспоминание Ортенберга;
- [ ] найти конкретную страницу `thefireofthewar.ru`, которую ПКДБ использовала как footnote 9;
- [ ] при нахождении печатного источника записать edition + page;
- [ ] отдельно искать фотографию/факсимиле рукописи с редакционной пометой, но не предполагать, что она сохранилась.

## 6. Что можно улучшить в статье уже сейчас

В разделе публикации безопасно добавить одно предложение:

> В Москве Симонов, по собственному позднему воспоминанию, прочёл `Сына артиллериста` Давиду Ортенбергу; редактор принял текст сразу, и поэма пошла в номер `Красной звезды`.

А красивую сцену с физической надписью **`В номер`** лучше пока оставить за скобками либо маркировать:

> По позднему воспоминанию Ортенберга, приведённому Приморской краевой детской библиотекой, он написал на рукописи `В номер`.

Для main longform первая, более строгая формула предпочтительнее.

## Итог

Цепочка `Архангельск → Москва → Ортенберг → номер Красной звезды` уже хорошо поддержана собственным рассказом Симонова и согласуется с выпуском 7 декабря. Ортенберговская деталь `В номер` — сильное и выразительное подтверждение, но её **exact original locus ещё должен быть найден**, прежде чем статья будет цитировать её без вторичной атрибуции.
