## Масштабирование
Каждый объект: постоянный ID, ID поэта, вид места, местоположение, дата, историческая справка, хронология, не менее двух независимых источников, локальные оптимизированные фотографии с правами и проверяемыми хешами. Не публиковать заглушки. Валидатор проверяет структуру и байты, не историческую истинность. Дизайн — единая адаптивная композиция, фото без принудительной обрезки, светлая/тёмная темы, якоря, раскрываемые источники.
Кандидаты: Пушкин — Михайловское; Лермонтов — Тарханы; Есенин — Константиново; Блок — Шахматово; Маяковский — Багдади; Ахматова — Фонтанный дом; Цветаева — Елабуга; Тютчев — Овстуг. Для остальных поэтов — по каталогу. Это исследовательская очередь, не опубликованные карточки.

## W2 — Михайловское, Константиново, Шахматово

Три новые экспозиции в \`estates.ts\`; 6 фотографий из проверенных карточек Wikimedia Commons. Каждая карточка хранит оригинальный URL, SHA-256 полученного полного оригинала и WebP, размеры, авторство и условия использования. Музейные реконструкции обозначены в тексте. История каждого места опирается на ссылки в реестре. Остальные поэты остаются исследовательской очередью без пустых секций. Public domain у двух фотографий Zac allan — самостоятельное освобождение правообладателем, не лицензия CC BY.

## W3 — Фонтанный дом, Овстуг, Воробьёвка, Переделкино

## W4 — Багдати, Градницы, Борисоглебский переулок, Воронеж
Четыре новые экспозиции (12 из 16 авторов), шесть фотографий; данные и атрибуция в silverAgePlaces.ts и соответствующих media.json. Подлинный дом Гумилёвых перенесён из Слепнёва в Градницы в 1935 году. Дом Мандельштама — один из нескольких воронежских адресов, не памятник и не музейная реконструкция. Для Багдати отдельно указаны учреждение музея (1940) и открытие посетителям (1941). Источники — Государственный музей Маяковского, Тверской музей, ИМЛИ РАН, Дом-музей Цветаевой, ТИЦ Воронежа; оригинальные карточки Commons и лицензии закреплены в реестре.

Общий адаптивный компонент использует CSS container queries относительно ширины колонки. Однофотографические экспозиции не создают пустую колонку. Тест qa/memory-places-responsive.spec.mjs проверяет 320, 390, 768, 1440 px в двух темах для одной, двух и трёх фотографий; сохраняет снимки реальных viewport с навигацией сайта. Проверяются контраст, геометрия, фото, якорь и раскрытие источников. SEO-манифест регенерирован штатным генератором: fingerprint учитывает данные места, хеши медиа и общий компонент/стиль для соответствующего поэта. Исправлена причина падения verify W3 (stale discovery manifest). Не отключать gate.

## Museum Edition — единый дизайн и runtime
- Заглавная фотография сразу после названия, места и даты. Облегчённая редакционная композиция без вложенных карточек, масштабируемая типографика, линейные факты и хронология, фото без обрезки.
- Галерея использует ResilientImage, useDialogSurface, portal, общий стек модалей, восстановление фокуса, Escape, навигацию стрелками и явные кнопки изменения масштаба. Одна фотография — без лишних стрелок. Источник, автор, лицензия и преобразования доступны в подписи и галерее.
- Страница поэта загружает MemoryPlaces через React.lazy, а ссылка перехода использует индекс ревизий. Нет статического импорта всего реестра в маршрут. Бюджет PoetDetailPage: 44,5 КиБ / 50,8 КиБ (прежнее нарушение 103,9 КиБ устранено), общий бюджет JS пока проходит с малым запасом; до расширения W5 следует вынести данные в генерируемые по поэтам JSON, не увеличивать лимит. Discovery-манифест регенерируется штатно.
- QA_CAPTURE_MEMORY=1 включает снимки для локального визуального аудита; по умолчанию тесты больше не накапливают изображения. Проверки покрывают обе темы, 320/390/768/1440px, 1/2/3 снимка, галерею, прямой hash, фокус и сенсорное устройство. CustomCursor уже использует fine-pointer capability gate; узкая desktop-эмуляция сама по себе не является touch-устройством.

## Poet-scoped delivery
Canonical editorial records remain in src/data/memory-places. npm run memory:generate produces deterministic public/data/memory-places/<poet>.json and a small revision index. Both Vite and validate:library reject stale or unexpected generated files. The route imports only the revision index and lazy-loads the shared exhibit; the exhibit fetches only the requested poet's revisioned JSON, aborts on unmount, and offers a retry on failure. Missing poets incur no exhibit fetch. The route budget and all 14 manifest entries remain unchanged; build budget is not relaxed. Generated resources are deployment artifacts, not a second authoring source. Regenerate after additions and verify discovery artifacts with the existing generator.

## W6 — редакционная композиция и галерея
- Галерея вписывает изображение в обе оси доступной области с сохранением пропорций и ограничением естественной ширины; Zoom — 2× от вписанного размера. При увеличении центр сохраняется, область доступна клавиатуре. Проверка измеряет реальную геометрию, включая низкий альбомный viewport iPhone.
- Хронология предшествует дополнительному снимку в DOM и мобильном порядке; второй снимок дополняет историю, третий образует отдельный разворот с пояснением и цитатой. Типографика истории и примечаний — 16–17 px, техническая атрибуция отделена от музейной подписи. Десять подписей уточнены без изменения фотографий, прав, источников и хешей.
- Локальная приёмка: 69/69 браузерных тестов (Chromium, Android, WebKit), включая обе темы, 320/390/768/1440 px; дополнительная геометрическая проверка всех 16 экспозиций в desktop dark и mobile light — 32/32. На примере Лермонтова дисбаланс колонок 615→143 px; высота desktop 2662→2392 px, mobile 3577→3757 px при увеличенном читаемом тексте. Контрольные уменьшенные снимки разворотов просмотрены. Все 14 бюджетов маршрутов проходят; серверный CI и production принимаются отдельно.

## W8 — устойчивость при недоступности фотографий
- Проверены 16/16 экспозиций при 200% размера текста в WebKit 320×568: переполнений нет.
- При отказе загрузки фотографии кнопка сообщает о недоступности снимка, галерея объявляет ошибку в существующей live-region, Zoom недоступен до успешной загрузки. Сохраняются пропорции, подпись, атрибуция, закрытие и возврат фокуса. Повторное открытие галереи позволяет повторить загрузку без нового механизма retry.
- Расширен существующий тест однофотографической галереи: отказ сети, доступное имя, объявление ошибки, отключение Zoom, сохранение лицензии, возврат фокуса и восстановление после открытия. 6/6 адресных тестов в Chromium, Android и WebKit, 6/6 адаптивных тестов в Chromium (обе темы и четыре ширины); TypeScript, сборка, discovery и 14 бюджетов проходят.
