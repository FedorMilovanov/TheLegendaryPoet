# Места памяти — общий контракт
Единый реестр `src/data/memory-places/index.ts` и общий компонент `MemoryPlaces.tsx`. Новые места добавляются как данные, не как отдельные компоненты или маршруты. Не вмешивается в Hall v3. Пустые разделы отсутствуют.

## Пятигорск
Источники сверены 26.11.2026:
- https://www.culture.ru/institutes/6151/pamyatnik-m-yu-lermontovu-v-pyatigorske
- https://old.skunb.ru/node/4205
- https://omir.pgu.ru/pervyj-v-rossii/
- https://rvb.ru/19vek/lermontov/ss4/vol2/poems/465.html (часть I, строфа 6; сохраняется написание «Бешту», «встает»).
Высота монумента 5,65 м; фигуры 2,35 м. Дата открытия 16 (28) августа 1889. Памятник не является обелиском на месте дуэли.

Три изображения — CC BY-SA 4.0 с сохранением лицензии производных WebP, автора, ссылки на оригинал и указанием изменений. Исходные и производные SHA-256, размеры и права — в `src/data/memory-places/lermontov-pyatigorsk-media.json`. Лицензии изображений не меняют UNLICENSED проекта. Снимок открытия Раева не включён до точной сверки музейной карточки и правового статуса репродукции; не выдавать цифровое оживление за архивный снимок.

## Масштабирование
Каждый объект: постоянный ID, ID поэта, вид места, местоположение, дата, историческая справка, хронология, не менее двух независимых источников, локальные оптимизированные фотографии с правами и проверяемыми хешами. Не публиковать заглушки. Валидатор проверяет структуру и байты, не историческую истинность. Дизайн — единая адаптивная композиция, фото без принудительной обрезки, светлая/тёмная темы, якоря, раскрываемые источники.
Кандидаты: Пушкин — Михайловское; Лермонтов — Тарханы; Есенин — Константиново; Блок — Шахматово; Маяковский — Багдади; Ахматова — Фонтанный дом; Цветаева — Елабуга; Тютчев — Овстуг. Для остальных поэтов — по каталогу. Это исследовательская очередь, не опубликованные карточки.

## W2 — Михайловское, Константиново, Шахматово

Три новые экспозиции в \`estates.ts\`; 6 фотографий из проверенных карточек Wikimedia Commons. Каждая карточка хранит оригинальный URL, SHA-256 полученного полного оригинала и WebP, размеры, авторство и условия использования. Музейные реконструкции обозначены в тексте. История каждого места опирается на ссылки в реестре. Остальные поэты остаются исследовательской очередью без пустых секций. Public domain у двух фотографий Zac allan — самостоятельное освобождение правообладателем, не лицензия CC BY.

## W3 — Фонтанный дом, Овстуг, Воробьёвка, Переделкино

Четыре новых объекта в memorialHomes.ts; восемь фотографий с установленными авторами, лицензиями и SHA-256 оригиналов и производных. Историческая основа — Государственный литературный музей, ИМЛИ РАН, Большая российская энциклопедия, Культура.РФ, музей-усадьба Фета и администрация Санкт-Петербурга. Ссылки на источники сохранены в каждой экспозиции. Овстуг обозначен как воссозданное здание, интерьеры Воробьёвки — как музейная реконструкция. Фотография Софии Юрашевич передана автором в public domain. Для карточек с двумя фотографиями исправлено отображение содержательного примечания.

## W4 — Багдати, Градницы, Борисоглебский переулок, Воронеж
Четыре новые экспозиции (12 из 16 авторов), шесть фотографий; данные и атрибуция в silverAgePlaces.ts и соответствующих media.json. Подлинный дом Гумилёвых перенесён из Слепнёва в Градницы в 1935 году. Дом Мандельштама — один из нескольких воронежских адресов, не памятник и не музейная реконструкция. Для Багдати отдельно указаны учреждение музея (1940) и открытие посетителям (1941). Источники — Государственный музей Маяковского, Тверской музей, ИМЛИ РАН, Дом-музей Цветаевой, ТИЦ Воронежа; оригинальные карточки Commons и лицензии закреплены в реестре.

Общий адаптивный компонент использует CSS container queries относительно ширины колонки. Однофотографические экспозиции не создают пустую колонку. Тест qa/memory-places-responsive.spec.mjs проверяет 320, 390, 768, 1440 px в двух темах для одной, двух и трёх фотографий; сохраняет снимки реальных viewport с навигацией сайта. Проверяются контраст, геометрия, фото, якорь и раскрытие источников. SEO-манифест регенерирован штатным генератором: fingerprint учитывает данные места, хеши медиа и общий компонент/стиль для соответствующего поэта.
