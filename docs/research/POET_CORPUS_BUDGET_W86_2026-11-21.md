# W86 — корпус стихотворений: удаление дублей из клиентского fallback

Дата: 2026-11-21. Контрольная база — W85 PR #608 `6b8e2d504d24d6d3d94dafebbbdac7e114894604`. Техническая оптимизация без редакционных правок; не разрешает самостоятельный релиз.

## Системная причина и область

`scripts/supplementary-poet-artifacts.ts` имеет один canonical источник (модули `src/data/library/*.ts`) и две формы доставки: сокращённые `supplementaryPoets.generated.ts` для общего runtime и полные `public/data/poets/<id>.json` для каждой из 11 расширенных страниц. Старый fallback сохранял внутри общего JS по 32 стихотворениям все `analysis` и `biblicalPerspective`, хотя те же тексты уже находились в versioned JSON. В результате общий JavaScript почти превышал фиксированный бюджет: W85 **1755.5 / 1757.8 KiB**.

**Единственный владелец изменения:** генератор `scripts/supplementary-poet-artifacts.ts`. Пострадавшая поверхность — 11 авторов расширенной библиотеки, включая 5 классиков с ограниченным локальным fallback. Нет отдельной второй ручной картотеки, нет изменений Hall, Reader, API, бюджетов, маршрутов, прав на тексты.

## Исправление

В fallback `poems` удалены только необязательные длинные `analysis` и `biblicalPerspective`. Сохранены:
- Полные тексты резервных стихов, стабильные `id`, `title`, `year`, `yearNote`, `editionYear`, `yearLabel`;
- `sourceUrl`, `textualNote`, `textualSourceUrl`, `cycle`, `epigraph`, `rating` и признаки текстового фрагмента;
- Прежние 3–5 опубликованных fallback-текста у Pushkin/Lermontov/Tyutchev/Yesenin/Blok, а также существующие fallback-стихи остальных шести авторов;
- Весь научный и нравственно-библейский анализ **в полной canonical JSON**; его доставка осуществляется тем же `loadSupplementaryPoet(id, signal)`, как и ранее.

При недоступной сети редакционный интерфейс уже показывает: «Не удалось загрузить полный корпус стихов и биографию. Показана резервная подборка». В таком режиме стихи и подтверждения источников читаются без аналитических блоков, которые не должны дублироваться в глобальном JS. Существующий fallback намеренно менее полный, чем онлайн-страница. Этот компромисс открыто проверен, не скрыт пользователю.
