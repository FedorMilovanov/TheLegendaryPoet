## 4. Почему нельзя угадывать child-node ID

В поисковом индексе ГПИБ видны отдельные номерные узлы других выпусков, и у соседних выпусков встречается последовательная нумерация node IDs. Это создаёт соблазн арифметически восстановить URL № 288.

**Так делать в evidence ledger нельзя.**

Причины:

- внутренний node ID — технический идентификатор платформы, а не номер газеты;
- последовательность может иметь разрывы;
- даже если guessed URL откроется, его нужно прочитать и подтвердить заголовком/датой;
- publication gate строится на объекте, а не на совпадении арифметики.

Поэтому exact child node остаётся:

**unknown / discover, do not infer**.
