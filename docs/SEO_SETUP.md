# SEO и подключение поисковых кабинетов

Продакшен-адрес проекта: **https://thelegendarypoet.ru/**

## Что уже настроено в репозитории

- единый canonical на собственном домене;
- уникальные `title`, `description`, Open Graph и Twitter Cards;
- JSON-LD для сайта, организации, статей, поэтов и музыкальных публикаций;
- статические HTML-страницы для всех публичных маршрутов, чтобы прямые ссылки отдавали `200 OK`, а не SPA-fallback со статусом 404;
- `robots.txt` и автоматически генерируемый `sitemap.xml`;
- личный архив и незавершённый Зал Поэтов исключены из sitemap и закрыты через `noindex`;
- автоматическая отправка канонических URL через IndexNow после успешного деплоя;
- подтверждение Яндекс.Вебмастера двумя способами: HTML-файл и meta-тег.

## 1. Яндекс.Вебмастер

Файл уже размещён в корне:

`https://thelegendarypoet.ru/yandex_db80f976814c7327.html`

Код подтверждения: `db80f976814c7327`.

После завершения текущего GitHub Pages deploy:

1. В Яндекс.Вебмастере нажмите **«Подтвердить»**.
2. Откройте **Индексирование → Файлы Sitemap**.
3. Добавьте `https://thelegendarypoet.ru/sitemap.xml`.
4. В инструменте проверки URL отправьте главную страницу и несколько важнейших материалов на переобход.

Файл и meta-тег нельзя удалять: Яндекс периодически перепроверяет права.

## 2. Google Search Console

### Предпочтительный способ: доменный ресурс

Добавьте ресурс типа **«Доменный ресурс»**: `thelegendarypoet.ru`.
Google покажет уникальную TXT-запись. Её нужно добавить в DNS домена у регистратора. Этот способ охватывает HTTPS/HTTP и варианты с `www` без отдельных подтверждений.

### Альтернатива: ресурс с префиксом URL

Добавьте `https://thelegendarypoet.ru/`, выберите **HTML-тег** и скопируйте только значение `content` из строки:

```html
<meta name="google-site-verification" content="ВАШ_УНИКАЛЬНЫЙ_КОД" />
```

Вставьте код в `search-verification.json`:

```json
{
  "google": "ВАШ_УНИКАЛЬНЫЙ_КОД",
  "bing": "",
  "pinterest": ""
}
```

После deploy проверьте исходный код главной страницы и нажмите **«Подтвердить»**. Затем в разделе **Sitemaps** добавьте:

`https://thelegendarypoet.ru/sitemap.xml`

Для нескольких новых или особенно важных страниц используйте **Проверку URL → Запросить индексирование**. Массово повторять запросы не нужно.

## 3. Bing Webmaster Tools

Самый простой вариант — после подтверждения Google импортировать сайт из Google Search Console. Bing перенесёт подтверждённый ресурс и sitemap.

При ручной проверке выберите meta-тег `msvalidate.01`, скопируйте его значение и добавьте в `search-verification.json`:

```json
{
  "google": "КОД_GOOGLE_ЕСЛИ_ЕСТЬ",
  "bing": "КОД_BING",
  "pinterest": ""
}
```

После deploy добавьте тот же sitemap: `https://thelegendarypoet.ru/sitemap.xml`.

## 4. IndexNow

В корне сайта уже опубликован ключ:

`https://thelegendarypoet.ru/189937c25bd79e9d675311b76f9481854c85722f.txt`

Workflow `.github/workflows/indexnow.yml` запускается после успешного GitHub Pages deploy и отправляет URL из sitemap в IndexNow. Это помогает участвующим поисковикам быстрее узнавать о добавленных, изменённых и удалённых страницах.

## 5. Pinterest — только если понадобится

Для подтверждения домена Pinterest вставьте значение `p:domain_verify` в поле `pinterest` файла `search-verification.json`, затем дождитесь deploy и нажмите подтверждение в Pinterest.

## 6. Аналитика

Аналитика не влияет напрямую на позиции, но нужна для оценки поискового трафика. Проект поддерживает переменные сборки:

| Переменная | Значение |
|---|---|
| `VITE_YANDEX_METRIKA_ID` | номер счётчика Яндекс.Метрики |
| `VITE_GA_ID` | идентификатор Google Analytics 4 вида `G-...` |

Их следует хранить в **Settings → Secrets and variables → Actions → Variables**, а не прописывать в исходниках.

## Контроль после каждого крупного обновления

1. Убедиться, что deploy завершился успешно.
2. Проверить `robots.txt` и `sitemap.xml` на продакшен-домене.
3. Проверить canonical и robots в исходном HTML важной страницы.
4. Посмотреть отчёты индексирования в Google и Яндексе.
5. Не удалять файлы и meta-теги подтверждения после успешной проверки.
