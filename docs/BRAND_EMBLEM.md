# Эмблема THE LEGENDARY POET

## Канонический образ

Эмблема — выбранная владельцем проекта эпическая безликая фигура в высоком остром капюшоне и тяжёлом чёрно‑синем плаще. Лицо полностью скрыто большой глубокой пустотой. Холодное голубое контровое свечение подчёркивает капюшон, широкие плечи и длинные складки ткани; нижняя часть плаща спокойно уходит в темноту без рваных лоскутов.

В образе **нет нимба, кольца, книги, крыльев, монограммы `LP`, глаз, лица, нагрудного кристалла и религиозной символики**.

Бренд-система состоит из нескольких специализированных поверхностей:

- интерактивный многослойный inline‑SVG — `src/components/BrandMark.tsx`;
- автономный детализированный вектор — `public/brand-emblem.svg`;
- оптически упрощённый вектор для 16–32 px — `public/brand-mark-micro.svg`;
- монохромный силуэт с настоящей пустотой лица для Safari pinned tab — `public/brand-emblem-mask.svg`;
- выбранный оптимизированный мастер‑арт — `public/brand-emblem-master.webp` (320×320), сохранённый только как источник консервативных PNG/PWA/OG‑вариантов.

Runtime‑компонент и автономные SVG не содержат `<image>`, растровой подложки, прямоугольной рамки или запасного персонажа. Ревизия `cloak-20260726-5` пробивает старые кеши favicon, manifest, Windows tile, Open Graph и Schema.org.

## Геометрический контракт

Главный знак строится не как условная пиктограмма, а как система независимых слоёв:

- высокая острая геометрия капюшона с центральным швом;
- большая чёрная пустота лица, занимающая основную часть внутреннего проёма;
- широкое соотношение плеч к капюшону;
- перекрещивающиеся воротные пласты;
- несколько крупных и вторичных складок тяжёлого плаща;
- асимметричный контровой свет и редкие энергетические линии;
- мягкая атмосферная глубина только в средних и крупных размерах.

Малая версия намеренно не является автоматическим уменьшением большого SVG: она перерисована в `32×32`, имеет более толстый внешний контур, меньше деталей и сохраняет узнаваемую пустоту лица при 16 px.

## Где используется

- шапка, подвал и переходы между страницами — интерактивный `BrandMark`;
- вкладка браузера — предпочтительный `brand-mark-micro.svg`, затем PNG‑fallback `favicon-16.png` и `favicon-32.png`;
- Apple Touch — `apple-touch-icon.png`;
- PWA/Android — `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`;
- Windows tile — `mstile-150x150.png`;
- Schema.org — `icon-512.png`;
- предпросмотр ссылки — `og-image.jpg` (1200×630);
- Safari pinned tab — `brand-emblem-mask.svg`;
- технический маркер опубликованной ревизии — `brand-release.txt`.

Детерминированные исходники мастер‑арта и PNG‑favicon хранятся в `src/brand-assets/*.b64`. Команда `npm run brand:materialize` восстанавливает их и через FFmpeg заново производит Apple, PWA/Android, Windows и Open Graph варианты. SHA‑256 мастер‑арта, форматы и размеры производных файлов проверяются автоматически.

## Интерактив

Интерактив включается только при реальном hover и не содержит постоянных циклов:

- фигура приподнимается менее чем на пиксель;
- масштаб увеличивается примерно на 2%;
- контур капюшона и плеч мягко дорисовывается;
- складки расходятся на доли пикселя;
- внешняя энергия становится глубже, но не превращается в неоновое кольцо.

На `sm`‑версии не рендерятся тяжёлый атмосферный blur и вторичные швы. `useReducedMotion()` полностью отключает hover‑движение для пользователей с уменьшенной анимацией.

## Нельзя

- возвращать растровую картинку как runtime‑эмблему или помещать под SVG запасной персонаж;
- добавлять книгу, крылья, дугу/нимб, лицо, глаза, читаемый текст или нагрудный источник света;
- добавлять православные купола, кресты или конфессиональные знаки;
- подсвечивать прямоугольный контейнер вместо самой формы;
- применять бесконечную пульсацию, вращение или тяжёлый blur на 44‑пиксельной версии;
- менять плавный низ плаща на рваные лоскуты;
- генерировать новый визуальный образ вместо выбранного владельцем референса без отдельного согласования;
- считать задачу завершённой только по наличию коммита.

## Проверки

- `npm run validate:brand` проверяет слой капюшона, глубокую пустоту лица, складки, воротник, контровой свет, отсутствие растра/рамки/кристалла, favicon/manifest/cache version и детерминированные platform‑fallbacks;
- `qa/brand-emblem.spec.mjs` измеряет пропорции пустоты, капюшона и плеч, снимает отдельные idle/hover‑кадры, проверяет изменение только нужных SVG‑слоёв и повторяет контракт на основных маршрутах;
- полный `npm run check` включает TypeScript, бренд‑валидацию, production build, asset budgets и prerender;
- финальная браузерная матрица обязана пройти Chromium, Android Chrome и iPhone Safari/WebKit;
- после слияния публикация подтверждается фактической выдачей `thelegendarypoet.ru`, точной ревизией и release sentinel.
