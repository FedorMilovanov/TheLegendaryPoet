# Эмблема THE LEGENDARY POET

## Канонический образ

Эмблема — выбранная владельцем проекта эпическая безликая фигура в глубоком капюшоне и тяжёлом чёрно‑синем плаще. Лицо полностью скрыто. Холодное голубое контровое свечение и дымчатая энергия подчёркивают силуэт, а нижняя часть плаща плавно растворяется в тумане и темноте.

В образе **нет нимба, кольца, книги, крыльев, монограммы `LP` и религиозной символики**.

- канонический визуальный SSOT: `public/brand-emblem.svg`;
- lossless WebP‑производная для интерфейса: `public/brand-emblem-master.webp` (512×512);
- интерактивный компонент: `src/components/BrandMark.tsx`;
- favicon: `public/favicon.svg`;
- чистый монохромный вектор для Safari pinned tab: `public/brand-emblem-mask.svg`.

Векторный силуэт находится прямо в SVG‑контейнере и React‑компоненте, поэтому эмблема не исчезает при задержке или ошибке загрузки WebP. `brand-emblem-master.webp` больше не является отдельным скрытым первоисточником: это детерминированная lossless‑производная того же принятого вектора. Она предзагружается из `index.html`, чтобы в шапке не было вспышки пустого места.

## Где используется

- шапка, подвал и переходы между страницами — `BrandMark`;
- вкладка браузера — `favicon.svg`, `favicon-16.png`, `favicon-32.png`;
- Apple Touch — `apple-touch-icon.png`;
- PWA/Android — `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`;
- Windows tile — `mstile-150x150.png`;
- Schema.org — `icon-512.png`;
- предпросмотр ссылки — `og-image.jpg` (1200×630), собранный из того же векторного образа;
- Safari pinned tab — `brand-emblem-mask.svg`.

## Воспроизводимость и целостность

Бинарные производные упакованы в `src/brand-assets/assets.part*.b64`. `src/brand-assets/manifest.json` фиксирует:

- SHA‑256 канонического SVG;
- полный список, размеры, MIME, геометрию и SHA‑256 девяти производных;
- длину и SHA‑256 полного архива;
- длину, decoded size и SHA‑256 каждой независимо кодированной Base64‑части.

`npm run brand:materialize` сначала проверяет каждую часть, затем полный архив и каждую запись. Только после полной проверки файлы атомарно публикуются в `public/`. Повреждённая или неполная часть не может создать усечённый WebP/PNG/JPEG.

Для осознанной пересборки:

```bash
python -m pip install cairosvg==2.8.2 pillow==11.3.0
python scripts/rebuild-brand-assets.py
npm run validate:brand
```

Не редактировать растровые производные, `manifest.json` или Base64‑части вручную.

## Интерактив

При наведении фигура едва приподнимается и увеличивается, холодное свечение становится глубже, а нижний туман мягко расширяется. Никаких вращений, раскрывающихся «крыльев», пульсирующей книги или яркой игровой анимации. Глобальный `MotionConfig reducedMotion="user"` уважает настройку уменьшения движения.

## Нельзя

- возвращать предыдущую эмблему с книгой, крыльями или дугой/нимбом;
- добавлять лицо, глаза или читаемый текст внутрь эмблемы;
- добавлять православные купола, кресты или конфессиональные знаки;
- менять плавное растворение нижнего края плаща на рваные лоскуты;
- копировать SVG с фиксированными `id`: React‑компонент обязан использовать `useId`;
- менять канонический вектор или генерировать новый визуальный образ без отдельного согласования;
- обходить manifest/архив прямым коммитом случайных бинарников.

## Проверки

- `npm run validate:brand` — векторный SSOT, manifest, архив, размеры/форматы производных, preload, метаданные, PWA и share preview;
- `qa/brand-emblem.spec.mjs` — размеры, уникальность SVG id, hover, отказоустойчивость без WebP, маршруты и отсутствие книги/крыльев/нимба;
- `npm run check` включает бренд‑валидацию.
