# Эмблема THE LEGENDARY POET

## Канонический источник v2

Единственный художественный эталон:

`qa/reference/brand-emblem-canonical-reference.webp`

Reference id: `canonical-hooded-figure-v2-clean-base`.

Эталон имеет высокий многослойный капюшон, широкую абсолютно чёрную пустоту лица, тяжёлый собранный клобук, широкую мантию, крупные складки и холодную электрическую ауру вокруг головы, плеч и боков. Низ остаётся тёмным и чистым — без обязательного дыма или светящейся подушки.

## Производственные поверхности

Синхронно обновляются:

- `src/components/BrandMark.tsx` — интерактивный inline React-SVG;
- `public/brand-emblem.svg` — детализированный автономный SVG;
- `public/brand-mark-micro.svg` — оптический знак 16–32 px;
- `public/brand-emblem-mask.svg` — Safari-mask с настоящим вырезом лица.

## Работа напрямую в MAIN

Марафон эмблемы ведётся непосредственно в `main`, чтобы художественные проходы не терялись в забытых ветках. Каждый проход оформляется одним атомарным коммитом поверх свежей вершины `main`; force-push запрещён.

В том же дереве обязаны находиться актуальные валидаторы, Browser QA, cache/version markers и `qa/brand-reference-evaluation.json` с точными Git blob SHA четырёх брендовых поверхностей.

## Обязательная проверка каждого прохода

Browser QA создаёт:

- `brand-reference-comparison-matrix.png` — REFERENCE / CURRENT CANDIDATE на 192, 96, 56, 32 и 16 px;
- `brand-reference-live-site-comparison.png` — REFERENCE / CURRENT SVG / EXACT-MAIN LIVE SITE;
- `brand-live-site-home-first-viewport.png` — первый экран реальной production-сборки.

Зелёный CI подтверждает только техническую целостность. Кандидат остаётся `NOT REFERENCE APPROVED`, пока пользователь не примет exact-main визуальное сравнение.

## Запрещено

- работать только от предыдущего SVG без открытого референса;
- возвращать нижний дым или туман;
- делать пустоту лица узкой каплей или аккуратной маской;
- превращать клобук в X, бант, усы или галстук;
- заменять тяжёлую ткань одинаковыми радиальными клиньями;
- скрывать слабую геометрию свечением;
- встраивать raster через `<image>`, base64 или `data:image`;
- ослаблять тесты ради принятия художественно слабого варианта.
