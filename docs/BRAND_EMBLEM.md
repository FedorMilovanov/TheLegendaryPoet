# Эмблема THE LEGENDARY POET

## Канонический образ

Эмблема — выбранная владельцем проекта эпическая безликая фигура в глубоком капюшоне и тяжёлом чёрно‑синем плаще. Лицо полностью скрыто. Холодное голубое контровое свечение и дымчатая энергия подчёркивают силуэт, а нижняя часть плаща плавно растворяется в тумане и темноте.

В образе **нет нимба, кольца, книги, крыльев, монограммы `LP` и религиозной символики**.

- выбранный мастер‑арт: `public/brand-emblem-master.png` (256×256, оптимизирован для интерфейсного масштаба);
- основной масштабируемый SVG‑контейнер: `public/brand-emblem.svg`;
- интерактивный компонент: `src/components/BrandMark.tsx`;
- favicon: `public/favicon.svg`;
- чистый монохромный вектор для Safari pinned tab: `public/brand-emblem-mask.svg`.

SVG‑контейнер и React‑компонент содержат отдельный кодированный векторный силуэт под мастер‑артом. Он не меняет выбранный образ, но не даёт эмблеме исчезнуть при задержке или ошибке загрузки PNG. Мастер‑арт также предзагружается из `index.html`, чтобы в шапке не было вспышки пустого места.

## Где используется

- шапка, подвал и переходы между страницами — `BrandMark`;
- вкладка браузера — `favicon.svg`, `favicon-16.png`, `favicon-32.png`;
- Apple Touch — `apple-touch-icon.png`;
- PWA/Android — `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`;
- Windows tile — `mstile-150x150.png`;
- Schema.org — `icon-512.png`;
- предпросмотр ссылки — `og-image.jpg` (1200×630), собранный из выбранного образа;
- Safari pinned tab — `brand-emblem-mask.svg`.

## Воспроизводимость ассетов

Шесть небольших платформенных файлов хранятся напрямую как неизменяемые Git‑объекты: favicon 16/32, Apple Touch, Android 192, Windows tile и JPEG share preview.

Три PNG, передача которых ранее повреждала бинарные данные, не коммитятся как готовые файлы:

- `public/brand-emblem-master.png`;
- `public/icon-512.png`;
- `public/icon-maskable-512.png`.

Их точные байты хранятся в `src/brand-assets/` как 12 независимых канонических Base64‑частей по не более чем 2000 исходных байт. Команда `npm run brand:materialize`:

1. проверяет полный и единственный набор частей;
2. декодирует каждую часть отдельно и проверяет её длину;
3. собирает каждый PNG только в памяти;
4. проверяет итоговые SHA‑256, PNG‑сигнатуру, IHDR, размеры и IEND;
5. сначала записывает все три временных файла и только затем заменяет файлы в `public/`;
6. параллельно проверяет SHA‑256 шести прямых бинарников;
7. отклоняет старый общий архив `assets.part*.b64` и WebP‑мастер.

Никаких сетевых загрузок, генерации нового образа или восстановления «похожего» файла во время сборки нет.

## Интерактив

При наведении фигура едва приподнимается и увеличивается, холодное свечение становится глубже, а нижний туман мягко расширяется. Никаких вращений, раскрывающихся «крыльев», пульсирующей книги или яркой игровой анимации. Глобальный `MotionConfig reducedMotion="user"` уважает настройку уменьшения движения.

## Нельзя

- возвращать предыдущую эмблему с книгой, крыльями или дугой/нимбом;
- добавлять лицо, глаза или читаемый текст внутрь эмблемы;
- добавлять православные купола, кресты или конфессиональные знаки;
- менять плавное растворение нижнего края плаща на рваные лоскуты;
- копировать SVG с фиксированными `id`: React-компонент обязан использовать `useId`;
- генерировать новый визуальный образ вместо выбранного владельцем референса без отдельного согласования;
- коммитить материализованные master/512/maskable PNG вместо их проверяемых исходных частей.

## Проверки

- `npm run brand:materialize` — точная сборка трёх PNG и проверка шести прямых бинарников;
- `npm run validate:brand` — части, итоговые SHA, SVG‑fallback, preload, отсутствие старых символов и файлов, метаданные, PWA и share preview;
- `qa/brand-emblem.spec.mjs` — размеры, уникальность SVG id, hover, отказоустойчивость без PNG, маршруты и отсутствие книги/крыльев/нимба;
- `npm run check` включает бренд‑валидацию.
