# Эмблема THE LEGENDARY POET

## Канонический образ

Эмблема — безликий «легендарный поэт» в капюшоне: тёмная мантия, холодный серебристо‑голубой контур и раскрытая книга с одной тонкой золотой линией. Это не монограмма `LP`, не портрет конкретного автора и не религиозная эмблема.

Канонический вектор: `public/brand-emblem.svg`. Он прозрачный и без рамки. Компонент интерфейса: `src/components/BrandMark.tsx`.

## Где используется

- шапка, подвал и переход между страницами — `BrandMark`;
- вкладка браузера — `public/favicon.svg`, `favicon-16.png`, `favicon-32.png`;
- iOS/PWA/Android/Windows — `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `mstile-150x150.png`;
- предпросмотр при публикации ссылки — `public/og-image.png` (1200×630);
- Schema.org publisher/logo — `icon-512.png`;
- Safari pinned tab — `brand-emblem.svg`.

Растровые варианты хранятся рядом с каноническим SVG и проверяются по сигнатуре и точным размерам командой `npm run validate:brand`.

## Интерактив

При наведении мантия едва раскрывается, контур и ореол становятся ярче, книга приподнимается, а свет над переплётом мягко пульсирует. Движение намеренно короткое и сдержанное; глобальный `MotionConfig reducedMotion="user"` уважает настройку уменьшения анимации.

## Нельзя

- возвращать старую монограмму `LP`;
- добавлять лицо, глаза, читаемый текст внутрь самой эмблемы;
- добавлять православные купола, кресты или конфессиональные знаки;
- помещать канонический `brand-emblem.svg` в карточку/рамку;
- копировать SVG с фиксированными `id`: React-компонент обязан использовать `useId`, иначе градиенты нескольких эмблем конфликтуют.

## Проверки

- `npm run validate:brand` — целостность SVG, метаданных, PWA и OG;
- `qa/brand-emblem.spec.mjs` — размеры, уникальность SVG id, hover, маршруты и растровые ассеты;
- `npm run check` включает бренд‑валидацию.
