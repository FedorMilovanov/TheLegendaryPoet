# Эмблема THE LEGENDARY POET

## Канонический образ

Эмблема — выбранная владельцем проекта эпическая безликая фигура в глубоком капюшоне и тяжёлом чёрно‑синем плаще. Лицо полностью скрыто. Холодное голубое контровое свечение и дымчатая энергия подчёркивают силуэт, а нижняя часть плаща плавно растворяется в тумане и темноте.

В образе **нет нимба, кольца, книги, крыльев, монограммы `LP` и религиозной символики**.

- оптимизированный мастер для интерфейса: `public/brand-emblem-master.webp` (320×320);
- интерактивный SVG‑компонент: `src/components/BrandMark.tsx`;
- иконки браузеров и платформ: PNG‑варианты выбранного образа;
- чистый монохромный вектор для Safari pinned tab: `public/brand-emblem-mask.svg`.

В шапке нет прежнего запасного векторного персонажа. Компонент показывает только утверждённый владельцем мастер‑арт внутри SVG. URL изображения и платформенных иконок версионированы как `cloak-20260725-2`, чтобы браузер, PWA и CDN не возвращали старую эмблему из кеша.

## Где используется

- шапка, подвал и переходы между страницами — `BrandMark`;
- вкладка браузера — `favicon-16.png`, `favicon-32.png`;
- Apple Touch — `apple-touch-icon.png`;
- PWA/Android — `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`;
- Windows tile — `mstile-150x150.png`;
- Schema.org — `icon-512.png`;
- предпросмотр ссылки — `og-image.jpg` (1200×630), собранный из выбранного образа;
- Safari pinned tab — `brand-emblem-mask.svg`.

Мастер и favicon воспроизводятся из самостоятельных Base64‑источников в `src/brand-assets/` командой `npm run brand:materialize`. SHA‑256 в бренд‑валидаторе не позволяет незаметно вернуть предыдущую эмблему.

## Интерактив

При наведении утверждённая фигура едва приподнимается и увеличивается, а холодное свечение становится немного глубже. Никаких вращений, раскрывающихся «крыльев», пульсирующей книги или яркой игровой анимации. Глобальный `MotionConfig reducedMotion="user"` уважает настройку уменьшения движения.

## Нельзя

- возвращать предыдущую эмблему или рисовать под мастер‑артом иной запасной персонаж;
- добавлять книгу, крылья, дугу/нимб, лицо, глаза или читаемый текст;
- добавлять православные купола, кресты или конфессиональные знаки;
- менять плавное растворение нижнего края плаща на рваные лоскуты;
- генерировать новый визуальный образ вместо выбранного владельцем референса без отдельного согласования.

## Проверки

- `npm run validate:brand` — мастер‑арт, отсутствие запасного старого силуэта, preload, cache version, метаданные, PWA и share preview;
- `qa/brand-emblem.spec.mjs` — размеры, hover, загрузка утверждённого WebP, маршруты и отсутствие книги/крыльев/нимба;
- `npm run check` включает бренд‑валидацию.
