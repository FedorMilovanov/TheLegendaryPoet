# Эмблема THE LEGENDARY POET

## Канонический образ

Эмблема — выбранная владельцем проекта эпическая безликая фигура в глубоком капюшоне и тяжёлом чёрно‑синем плаще. Лицо полностью скрыто. Холодное голубое контровое свечение и дымчатая энергия подчёркивают силуэт, а нижняя часть плаща плавно растворяется в тумане и темноте.

В образе **нет нимба, кольца, книги, крыльев, монограммы `LP` и религиозной символики**.

- утверждённый runtime‑мастер: `public/brand-emblem-master.webp` (320×320, валидный VP8 WebP);
- кодированный источник мастера: `src/brand-assets/master-320-q92.webp.b64`;
- интерактивный SVG‑контейнер: `src/components/BrandMark.tsx`;
- иконки браузеров и платформ: PNG‑производные того же утверждённого мастер‑арта;
- чистый монохромный вектор для Safari pinned tab: `public/brand-emblem-mask.svg`.

В шапке нет запасного векторного персонажа. Компонент показывает только утверждённый владельцем raster‑мастер внутри SVG. URL изображения и платформенных иконок версионированы как `cloak-20260725-2`, чтобы браузер, PWA и CDN не возвращали старую эмблему из кеша.

## Где используется

- шапка, подвал и переходы между страницами — `BrandMark`;
- вкладка браузера — `favicon-16.png`, `favicon-32.png`;
- Apple Touch — `apple-touch-icon.png`;
- PWA/Android — `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`;
- Windows tile — `mstile-150x150.png`;
- Schema.org — `icon-512.png`;
- предпросмотр ссылки — `og-image.jpg` (1200×630), собранный из утверждённого образа;
- Safari pinned tab — `brand-emblem-mask.svg`.

## Воспроизводимость и целостность

`src/brand-assets/approved-brand-manifest.json` фиксирует полный девятифайловый inventory: MIME, размеры, byte length, SHA‑256 и происхождение каждого файла. Три исходных runtime‑файла хранятся как канонический Base64; остальные платформенные PNG отслеживаются в Git и могут быть воспроизведены из мастера скриптом:

```bash
python -m pip install pillow==11.3.0
npm run brand:materialize
python scripts/rebuild-approved-brand-platform-assets.py
npm run validate:brand
```

`npm run brand:materialize`:

1. проверяет manifest и полный inventory;
2. требует канонический Base64;
3. сверяет decoded byte length и SHA‑256 каждого источника;
4. пишет runtime‑файлы через эксклюзивные временные файлы и атомарный rename;
5. затем проверяет наличие, размер и SHA‑256 всех девяти платформенных производных.

Повреждённый VP8, неполный набор иконок или случайно оставшийся файл из старого checkout больше не могут пройти CI незаметно. Реальную декодируемость WebP/PNG/JPEG дополнительно проверяет Playwright через `HTMLImageElement.decode()`.

## Интерактив

При наведении утверждённая фигура едва приподнимается и увеличивается, а холодное свечение становится немного глубже. Никаких вращений, раскрывающихся «крыльев», пульсирующей книги или яркой игровой анимации. Глобальный `MotionConfig reducedMotion="user"` уважает настройку уменьшения движения.

## Нельзя

- возвращать предыдущую эмблему или рисовать под мастер‑артом иной запасной персонаж;
- добавлять книгу, крылья, дугу/нимб, лицо, глаза или читаемый текст;
- добавлять православные купола, кресты или конфессиональные знаки;
- менять плавное растворение нижнего края плаща на рваные лоскуты;
- генерировать новый визуальный образ вместо выбранного владельцем референса без отдельного согласования;
- редактировать Base64, manifest или производные вручную без полного детерминированного rebuild и clean diff.

## Проверки

- `npm run validate:brand` — источник, manifest, девять файлов, форматы/размеры, SHA‑256, preload, cache version, PWA и share preview;
- `qa/brand-emblem.spec.mjs` — HTTP 200, реальное декодирование, размеры, hover, маршруты и отсутствие подменяющего персонажа;
- основной CI запускает `validate:brand` отдельным обязательным шагом до контентных и build‑проверок.
