# Эмблема THE LEGENDARY POET

## Главный канонический референс

Единственный художественный эталон производственной эмблемы:

`qa/reference/brand-emblem-canonical-reference.webp`

Reference id: `canonical-hooded-figure-v2-clean-base`.

Фактические закреплённые байты показывают **квадратную фигуру в полный рост**, а не погрудный крупный план. Канон фиксирует:

- небольшой высокий заострённый капюшон в верхней части композиции;
- глубокую абсолютно чёрную пустоту лица;
- узкий сдержанный клобук под лицом;
- длинный плащ, расширяющийся к низу в тяжёлый треугольный силуэт;
- преимущественно вертикальную массу ткани с редкими диагональными переломами;
- холодный ледяной контур по капюшону и наружным краям плаща;
- электрическую синюю ауру позади головы и по обоим внешним бокам;
- чистый тёмный нижний край без светящегося пола и без обязательной дымовой подушки.

Исходный пользовательский файл указан в `qa/reference/brand-reference-manifest.json` как `Figure mystérieuse dans une lueur bleue.png` и закреплён SHA-256.

`Siluette dans la brume sombre.png` — только дополнительный mood reference. Он не может подменять закреплённый квадратный файл, задавать геометрию или влиять на решение о принятии.

## Исправление контракта

Ранний текст марафона ошибочно назвал канон «погрудным крупным планом». Browser QA, который встраивает непосредственно `qa/reference/brand-emblem-canonical-reference.webp`, выявил это противоречие. С этого момента художественные проходы оцениваются только по фактической полнофигурной композиции закреплённого файла.

Нельзя выводить пропорции из словесного описания, если оно расходится с эталонными байтами. В таком случае приоритет всегда у неизменяемого изображения и его SHA-256.

## Производственные поверхности

Синхронно обновляются и блокируются Git blob SHA:

- `src/components/brandEmblemV18.svg` — текущая production-геометрия;
- `src/components/BrandMark.tsx` — React-обёртка, pointer ownership и доступное описание;
- `src/components/brandMotionV18.ts` — фазовый контроллер пробуждения;
- `public/brand-emblem.svg` — автономный SVG;
- `public/brand-mark-micro.svg` — отдельная оптическая геометрия для 16–32 px;
- `public/brand-emblem-mask.svg` — Safari mask с настоящим вырезом лица.

Runtime SVG не содержит `<image>`, base64, `<rect>`, canvas или растровой подложки.

## Архитектура «оживания»

`brandMotionV18.ts` реализует:

- чтение bounds при входе и изменении размера, а не на каждом pointer frame;
- один `requestAnimationFrame`-цикл только во время взаимодействия и возврата;
- затухающую пружинную физику по X, Y и интенсивности пробуждения;
- последовательность «аура → масса фигуры → контур и ткань»;
- независимую глубину атмосферы, энергии, фигуры, складок, капюшона, пустоты лица, воротника, контура и текстуры;
- состояние `active → settling → idle` без остаточных смещений;
- временный `will-change` только во время активности и возврата;
- исключение touch-параллакса;
- keyboard focus-visible усиление света;
- reduced-motion режим без геометрического движения;
- отсутствие React state updates внутри pointer hot loop.

Цель эффекта — ощущение пробуждения и пространственной глубины, а не дёрганье за курсором и не дешёвая неоновая вспышка.

## 24-проходный марафон

Исследовательский и инженерный контракт находится в:

`docs/research/BRAND_EMBLEM_SVG_MOTION_MARATHON_2026.md`

Техническая программа сохраняет 24 самостоятельных прохода, но художественные пункты должны читаться через исправленный полнофигурный composition lock. Следующие геометрические этапы: измерение реальных пропорций, длина плаща, положение капюшона, сужение верхней массы, наружные края, вертикальная ткань, ледяной контур и нерегулярная боковая аура.

## Обязательная проверка каждого глубокого прохода

Browser QA создаёт:

- `brand-reference-comparison-matrix.png` — эталон и кандидат на 256/192/128/96/64/56/44/32/24/16 px;
- `brand-reference-live-site-comparison.png` — референс, idle, entry и full awakening;
- `brand-interaction-state-matrix.png` — idle, фазы, четыре направления pointer depth и settled return;
- `brand-live-site-home-first-viewport.png` — фактический первый экран production-сборки;
- `brand-emblem-optical-size-matrix.png` — production и micro SVG;
- `brand-emblem-reduced-motion.png` — reduced-motion доказательство.

Проверки обязательны минимум в Chromium и WebKit. Зелёный CI доказывает только техническую целостность. Кандидат остаётся `not-reference-approved`, пока владелец не примет exact-head визуальные артефакты.

CI допускает один повтор упавшего теста в свежем worker/browser только для изоляции редкого падения процесса WebKit. Воспроизводимая ошибка остаётся красной после повторного запуска; утверждения и пороги не ослабляются.

## Запрещено

- работать от предыдущего SVG без открытого закреплённого референса;
- называть полнофигурный канон погрудным и строить по этому ошибочную геометрию;
- заменять production-геометрию кандидатом, который визуально хуже baseline;
- повышать score без новой сравнительной матрицы;
- скрывать слабую геометрию свечением;
- превращать пустоту лица в узкую каплю или аккуратную маску;
- превращать клобук в X, бант, усы или галстук;
- заменять тяжёлую ткань одинаковыми радиальными клиньями;
- добавлять яркий светящийся пол под нижний край;
- встраивать растровое изображение в runtime-эмблему;
- запускать вечный idle-loop;
- выполнять layout read/write на каждом pointer event;
- ослаблять тесты ради принятия художественно слабого кандидата.
