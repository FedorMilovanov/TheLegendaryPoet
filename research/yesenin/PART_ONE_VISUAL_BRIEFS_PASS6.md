## Media/provenance decision

- В production пока не добавляется ни одно новое изображение.
- Для архивных книжных объектов сначала нужен exact page capture, holding metadata и решение по правам.
- Для реконструкций обязательны видимая подпись `историческая реконструкция`, источник сценария и отсутствие ложной документальной атрибуции.
- NYPL finding aids используются как очередь item-level поиска, а не как автоматическая лицензия на изображения.
- Existing responsive AVIF/WebP pipeline должен использоваться только после отдельного media PR и визуального QA.
